## 1. 배경 및 목적

2026년 8월 3일 정부가 세제개편안을 발표했고, ISA 관련 핵심은 두 가지다.

1. **국내투자 전용 `생산적금융 ISA` 신설** — 총한도 2억원, 최대 10년, 대상 이자·배당소득 전액 비과세를 검토
2. **기존 ISA 제도 축소** — 미사용 납입한도 이월 폐지, 계약기간 총 5년 이내 제한

두 변화가 동시에 오기 때문에 "혜택이 늘었다"고만 보면 안 되고, "당근(생산적금융 ISA)과 제약(기존 ISA 축소)이 함께 온 개편"이라는 프레임으로 정리해야 사용자가 오해하지 않는다. 이 리포트는 기존 `/tools/isa-tax-calculator/`(일반형·서민형·농어민형 비과세 시뮬레이터)와 자연스럽게 연결되는 확장 콘텐츠이며, 계산기를 새로 만들 필요는 없다 — 정책 변화를 설명하고 계산기로 유도하는 리포트가 우선이다.

## 4. 착수 전 필수 확인 목록 (구현 전에 반드시 원문 대조)

아래 항목은 뉴스핌 기사·기재부 문답자료 요약만으로는 확정할 수 없어, 페이지 구현 전에 원문(기재부 보도자료 본문, 세법 개정안 조문)으로 재확인한다. 확인 전까지 비교표에는 "확인 필요" 배지를 붙인다.

### 5-2. 이월 폐지 예시 표

핵심 해설 문구(원안에는 없던 인사이트, 추가):
> "총 납입한도 1억원은 유지되지만, 이월이 폐지되고 계약기간이 5년으로 제한되면 이 한도를 다 채우려면 5년 동안 매년 2,000만원을 빠짐없이 납입해야 합니다. 결과적으로 총한도 자체의 의미가 약해지는 구조입니다."

### 5-3. 용어 설명 카드

- 생산적금융 ISA란? (기존 ISA와 무엇이 다른가)
- BDC란? (비상장기업투자회사 — 일반 개인투자자에게 생소한 용어이므로 1줄 정의 필수)
- 국민성장펀드란? (정부가 새로 지정한 펀드 유형이라는 점 설명)
- "전액 비과세"의 진짜 의미 — 국내주식 매매차익은 원래도 대부분 비과세이므로, 실질적 추가 혜택은 배당·분배금·이자소득에 있다는 점을 명확히 함 (원안 §3 내용 유지, 좋은 구조이므로 그대로 채택)
- 금융소득종합과세와의 관계 — 배당소득이 연 2천만원을 넘으면 원천징수(15.4%)로 끝나지 않고 종합과세로 넘어갈 수 있다는 점 추가 (원안에 없던 보완)

### 5-4. 투자 성향별 시나리오 (개인화 제거)

원안 §6~§7의 개인화된 조언을 아래처럼 일반화한다.

| 투자 성향 | 시나리오 방향 |
|---|---|
| 해외지수 ETF(S&P500·나스닥100 등) 중심 투자자 | 생산적금융 ISA는 해외 상품을 원칙적으로 제외하므로, 기존 ISA를 계속 활용하는 편이 유리할 수 있음 |
| 국내 배당주·금융지주 장기투자자 | 생산적금융 ISA의 "배당·이자 전액 비과세" 혜택이 상대적으로 큼 |
| 국내 개별주식 단기 매매 중심 | 매매차익은 원래도 비과세라 추가 혜택이 크지 않을 수 있음 |
| 청년(소득공제 대상 여부 확인 필요) | 10% 소득공제 검토 중이나 연령·요건 확정 전이므로 시행령 확인 필요 |

각 카드는 "~일 수 있음", "~검토 중" 어미를 유지하고 특정 인물을 지칭하지 않는다.

4. 생산적금융 ISA는 정말 세금이 하나도 없나요? ("전액 비과세"의 범위 — §5-3 설명 연결)
5. 청년 소득공제는 누가 받을 수 있나요? (요건 미확정, 확인 필요)
6. 지금 기존 ISA에 얼마나 넣어야 하나요? (일반론으로만 안내, "개인 재무 상황에 따라 다르며 세무 전문가·증권사 상담을 권장" 문구 포함 — 개인화 조언 대신 일반 원칙만 제공)
