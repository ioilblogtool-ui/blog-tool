## 1. 기획 의도

네이버와 엔비디아의 대규모 투자 뉴스는 단순 기업 뉴스보다 사용자가 헷갈리는 구조가 많다. 특히 `지분교환`, `제3자배정 유상증자`, `신주 발행`, `자사주 소각`, `희석률` 같은 용어가 한 번에 등장하기 때문에, 일반 투자자는 "내 주식이 줄어드는가", "4.5% 희석이면 주가도 4.5% 빠지는가", "이게 호재인가 악재인가"를 바로 알고 싶어 한다.

따라서 이 콘텐츠는 뉴스 해설만 하는 리포트보다, 사용자가 직접 숫자를 넣어 **신주 발행가격, 신규 투자자 지분율, 기존 주주 희석률, 내 보유지분 전후 변화, 희석 상쇄에 필요한 기업가치 상승률**을 계산하게 만드는 것이 적합하다. 비교계산소의 정체성인 "숫자로 판단하는 콘텐츠"와도 잘 맞는다.

네이버·엔비디아 사례는 이 계산기의 강력한 예시 데이터로 사용한다. NVIDIA 공식 발표는 NAVER·NVIDIA·Brookfield가 한국 AI 팩토리 인프라 확장을 추진하고, NVIDIA가 NAVER에 10억 달러 투자를 계획한다고 설명한다. Reuters 보도는 NAVER가 NVIDIA에 신주 720만 주를 발행해 약 1조4,810억 원을 조달하고, NVIDIA가 거래 후 약 4.5% 지분을 보유하는 구조로 정리했다.

결론적으로 첫 출시 조합은 **계산기 1개 + 사례 리포트 1개**가 가장 효율적이다. 계산기는 상시 검색 유입을 담당하고, 사례 리포트는 현재 이슈 검색을 흡수해 계산기로 보내는 역할을 한다.

## 5. 계산 로직

```typescript
interface DilutionInput {
  existingShares: number;
  newShares: number;
  investmentAmount: number;
  currentPrice?: number;
  ownedShares?: number;
  treasurySharesCancelled?: number;
}

interface DilutionResult {
  issuePrice: number;
  postMoneyShares: number;
  investorOwnershipRate: number;
  existingShareholderRate: number;
  dilutionRate: number;
  preMoneyValuation: number;
  postMoneyValuation: number;
  ownershipBefore?: number;
  ownershipAfter?: number;
  ownershipDilutionRate?: number;
  issueDiscountRate?: number;
  breakEvenValueIncreaseRate: number;
}
```

핵심 수식:

```text
최종 주식 수 = 기존 발행주식 수 + 신규 발행주식 수 - 소각 예정 자사주 수
신주 발행가격 = 투자금액 ÷ 신규 발행주식 수
신규 투자자 지분율 = 신규 발행주식 수 ÷ 최종 주식 수
기존 주주 지분율 = (기존 발행주식 수 - 소각 예정 자사주 수) ÷ 최종 주식 수
기존 주주 희석률 = 1 - 기존 주주 지분율
발행 할인율 = (현재 주가 - 신주 발행가격) ÷ 현재 주가
희석 상쇄 필요 상승률 = 1 ÷ 기존 주주 지분율 - 1
```

계산 예외 처리:

| 상황 | 처리 |
|---|---|
| 신규 발행주식 수가 0 이하 | 계산 불가 안내 |
| 기존 주식 수가 0 이하 | 계산 불가 안내 |
| 소각 주식 수가 기존 주식 수보다 큼 | 입력 오류 안내 |
| 투자금액이 0 이하 | 발행가격 계산 불가 |
| 현재 주가 미입력 | 할인율·현재 시총 계산 숨김 |
| 보유 주식 수 미입력 | 내 지분율 카드 숨김 |

## 12. 디자인 방향

- 첫 화면은 뉴스 카드가 아니라 계산기 입력과 결과가 바로 보이게 구성한다.
- 네이버·엔비디아 사례는 `프리셋`과 `사례 해설 박스`로 제공한다.
- 결과 카드에는 `단순 계산`, `참고`, `시뮬레이션` 배지를 붙인다.
- 희석률은 빨간색만 쓰지 않는다. 희석은 부정적 의미가 있지만 투자금 유입이 동시에 있으므로 중립적인 색상과 설명을 함께 사용한다.
- 유상증자·지분교환·구주매각 비교표는 모바일에서 가로 스크롤이 필요하다.
- 자사주 소각 입력은 고급 설정으로 접어두되, 네이버 사례에서는 차별화 포인트로 설명한다.

## 13. 리스크 및 주의사항

- 이번 건은 최신 기업 뉴스이므로 최종 공시와 조건이 바뀔 수 있다.
- NVIDIA 공식 발표에는 투자 조건과 별도 금융 확정 조건이 포함되어 있으므로 `확정 완료`처럼 쓰지 않는다.

- 자사주 소각은 소각 대상·시점·발행주식 수 반영 방식에 따라 계산 결과가 달라질 수 있다.
