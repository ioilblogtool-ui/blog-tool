## 1. 기획 의도

"코스피 레버리지 계산기"를 검색하는 사용자는 크게 두 갈래다. 하나는 "지금 이 정도 오르면/떨어지면 얼마 버는지" 단순 계산이 필요한 사용자, 다른 하나는 "분명 지수는 회복했는데 왜 내 레버리지 ETF는 아직 마이너스인가"라는 실제 경험에서 나온 의문을 가진 사용자다. 후자가 훨씬 검색 의도가 강하고 체류시간도 길다 — 레버리지 ETF의 핵심 위험인 **변동성 감소효과(디케이)**를 직접 겪었기 때문이다.

기존 계산기들(증권사·블로그 다수 존재)은 대부분 "지수 등락률 × 2배"만 보여주는 단순 계산기다. 이 계산기의 차별화 포인트는 **일별 등락 경로를 반영한 실제 복리 시뮬레이션**을 함께 보여줘서, "왜 단순 2배가 아닌지"를 숫자로 직접 체감하게 하는 것이다. 특히 "지수는 그대로인데 레버리지는 손실"이라는 박스권 시나리오를 기본 프리셋으로 강조하면, 이 계산기만의 훅이 된다.

추가로 2026년 7월은 시의성이 매우 강한 시점이다. 금융위원회가 2026-07-16 단일종목 레버리지 상품(ETF·ETN) 보완방안을 발표했고, 2026-07-24 조기시행 방안에 따라 **기본예탁금 현금 3천만원 요건이 내일(2026-07-31)부터 시행**된다. 이 규제 이슈는 코스피200 지수 레버리지가 아닌 개별 종목(삼성전자·SK하이닉스 등) 기초 레버리지 상품을 대상으로 하지만, "레버리지" 검색 자체의 트래픽을 크게 늘리는 뉴스 훅이므로 계산기 하단에 시의성 안내 블록으로 연결한다.

첫 배포는 **계산기 1개**로 충분하다. 규제 이슈 해설과 물타기·손실복구 계산기는 클러스터 확장 후보로 남겨둔다.

### 3-2. 변동성 감소효과(디케이) — 검증된 예시

지수가 100에서 시작해 첫날 +10%, 다음날 -9.09%면 지수는 정확히 100으로 복귀한다. 그러나 2배 레버리지는 첫날 +20%(120), 다음날 -18.18%(약 98.18)로 **지수는 원금 그대로인데 레버리지는 약 -1.82% 손실**이 된다. 이는 레버리지 ETF가 "기초지수 가격"이 아니라 "일간 수익률의 배수"를 매일 재조정(리밸런싱)해서 추종하기 때문에 발생하는 음의 복리효과다. 계산기의 핵심 훅으로 사용한다.

계산 방식: 단순 근사 공식(연변동성 기반 추정)보다 **일별 등락률을 실제로 복리 계산**하는 방식이 더 정확하고 사용자가 검증하기도 쉽다. 이 기획에서는 프리셋 시나리오별 일별 등락률 배열을 직접 곱복리 계산하는 방식을 채택한다 (아래 5장 계산 로직 참고).

### 3-3. 2026년 7월 규제 이슈 (계산기 하단 시의성 안내용, 팩트체크 완료)

## 4. 계산기 설계

### 4-1. 권장 H1

```text
코스피 레버리지 ETF 손익 계산기
```

### 4-2. 상단 설명

```text
코스피200이 10% 오르면 레버리지 ETF도 정확히 20% 오를까요? 레버리지 ETF는 기간 전체 수익률이 아니라 '하루 수익률'의 배수를 매일 재조정하며 추종합니다. 그래서 여러 날 보유하면 실제 누적수익률은 지수 누적수익률의 단순 배수와 달라집니다. 투자금액과 시장 흐름 시나리오를 선택해 실제 예상 손익을 계산해보세요.
```

### 4-3. InfoNotice 문구

```text
이 계산기는 프리셋 시나리오의 일별 등락률을 그대로 복리 계산한 참고용 시뮬레이션입니다. 실제 상품 수익률에는 운용보수, 선물 롤오버 비용, 추적오차, 시장가격과 순자산가치(NAV) 간 괴리, 거래·세금 비용이 추가로 반영되어 이 계산 결과와 다를 수 있습니다. 투자 권유가 아니며 실제 투자 판단에는 상품 투자설명서를 확인해야 합니다.
```

### 4-4. 입력 항목

| 입력 항목 | 기본값 | 필수 여부 | 설명 |
|---|---:|---|---|
| 투자원금 | 10,000,000원 | 필수 | 시뮬레이션 대상 투자금액 |
| 레버리지 배율 | 2배 | 필수 | 국내 표준 2배 / 해외 상품 비교용 3배 선택 |
| 시장 시나리오 (프리셋) | 박스권 반복장 | 필수 | 4개 프리셋 버튼 중 선택 (4-6 참고) |
| 연 운용보수 | 0.64% | 선택(고급 설정) | KODEX 레버리지 실제 보수율 기본값, 수정 가능 |

시나리오는 프리셋 버튼 선택 방식으로 시작하고, "직접 입력"(일별 등락률 여러 개 직접 입력)은 1차 배포 범위에서 제외하고 향후 확장 메모로 남긴다 (12-2 참고).

### 4-5. 프리셋 시나리오 (일별 등락률 배열)

| 프리셋 | 일별 등락률 (순서대로) | 서사 | 강조 포인트 |
|---|---|---|---|
| 박스권 반복장 (기본값·핵심 훅) | +5%, -5%, +5%, -5%, +5%, -5% | 지수는 오르내림을 반복하며 사실상 제자리 | "지수는 그대로인데 레버리지는 손실" |
| 완만한 상승 추세 | +2%×10일 (연속 10일 각 +2%) | 꾸준한 상승 추세 | 방향성 있는 추세장에서는 복리효과가 오히려 유리하게 작동할 수 있음(균형 서술) |
| 급등락 반복장 (2026년형) | +7%, -6%, +8%, -7%, +4%, -3% | 코스피 사이드카가 역대 최다로 발동된 2026년 실제 변동성 국면을 참고한 시나리오 | 지수는 소폭 플러스인데 레버리지는 마이너스가 될 수 있음 — `/reports/kospi-sidecar-record-2026/`과 내부 연결 |
| 완만한 하락장 | -2%×5일 (연속 5일 각 -2%) | 꾸준한 하락 | 하락장에서는 레버리지 손실이 단순 2배보다 더 커질 수 있음 |

각 프리셋 선택 시 "지수 누적 수익률"과 "레버리지 실제 누적 수익률"을 나란히 보여줘 괴리를 즉시 체감하게 한다.

## 5. 계산 로직

### 5-1. 타입 정의

```typescript
interface DailyScenario {
  id: "sideways" | "uptrend" | "volatileUp2026" | "downtrend";
  label: string;
  dailyIndexReturns: number[]; // 예: [0.05, -0.05, 0.05, -0.05, 0.05, -0.05]
  narrative: string;
}

interface LeverageCalcInput {
  principal: number;
  leverageMultiple: 2 | 3;
  scenario: DailyScenario;
  annualFeeRate: number; // 기본값 0.0064
}

interface LeverageCalcResult {
  indexCumulativeReturn: number;
  leverageSimpleReturn: number;       // 지수수익률 × 배율 (통념상 계산)
  leverageActualReturnPreFee: number; // 일별 복리 시뮬레이션 (보수 차감 전)
  decayGap: number;                   // leverageActualReturnPreFee - leverageSimpleReturn
  feeDrag: number;                    // 보수 차감분
  leverageFinalReturn: number;        // 보수까지 반영한 최종 추정 수익률
  finalAmount: number;
  indexOnlyFinalAmount: number;       // 비교용: 같은 원금을 지수 추종 상품에 투자했을 경우
  recoveryReturnNeeded: number | null; // 손실일 때만 값, 아니면 null
}
```

### 5-2. 핵심 수식 (일별 등락률 실제 복리 계산 방식)

```text
지수 누적값 = Π(1 + 일별등락률_i)  (i = 1..N)
레버리지 누적값 = Π(1 + max(배율 × 일별등락률_i, -1))  (하루 손실 -100% 하한)

지수 누적 수익률 = 지수 누적값 - 1
레버리지 단순 이론 수익률 = 지수 누적 수익률 × 배율
레버리지 실제 누적 수익률(보수 전) = 레버리지 누적값 - 1
디케이 갭 = 레버리지 실제 누적 수익률(보수 전) - 레버리지 단순 이론 수익률

보수 차감분 = 연보수율 × (거래일수 N / 252)
레버리지 최종 수익률 = 레버리지 실제 누적 수익률(보수 전) - 보수 차감분

최종 평가금액 = 투자원금 × (1 + 레버리지 최종 수익률)
지수만 투자했을 경우 평가금액 = 투자원금 × (1 + 지수 누적 수익률)

원금 복구 필요 상승률 = 레버리지 최종 수익률 < 0 ? (1 ÷ (1 + 레버리지 최종 수익률) - 1) : null
```

하루 등락률이 -50%(배율 2배 기준 -100%)를 넘는 값은 입력 자체를 프리셋으로만 제공하므로 발생하지 않지만, 향후 "직접 입력" 확장 시 하한 처리(`max(..., -1)`)를 반드시 유지한다.

### 5-3. 계산 예외 처리

| 상황 | 처리 |
|---|---|
| 투자원금 0 이하 | 계산 불가 안내 |
| 프리셋 미선택 | 기본값(박스권 반복장) 자동 적용 |
| 보수율 음수 입력 | 0으로 보정 |
| 레버리지 최종 수익률이 -100% 이하로 계산됨 | 이론상 발생하지 않도록 하루 하한(-100%) 처리로 방지, 최종값도 -99.9%에서 표시 하한 |

결론: **1순위로 빠르게 구현할 가치가 높다.** 규제 리포트(클러스터 2번)는 시의성이 매우 높으므로 이 계산기 배포 직후 이어서 검토하는 것을 권장한다.
