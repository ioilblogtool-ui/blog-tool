## 5. 입력 필드와 모드

### 간편 모드

| 필드 | 기본값 | 검증·도움말 |
|---|---|---|
| 기준 연도·월 | 검증된 기간의 2027 월 | 연도만으로 기간별 상한을 감추지 않음 |
| 세전 월 급여 | 빈칸 | 원 단위, 음수 불가, 성과급 포함 여부 설명 |
| 비과세 급여 | 0 | 전체 급여보다 클 수 없음, 법정 비과세 여부는 사용자가 확인 |
| 국민연금 적용 | 예 | 개별 자격 판정을 대신하지 않음 |
| 건강보험 적용 | 예 | 장기요양 적용·면제는 고급 옵션에서 관리 |
| 고용보험 적용 | 예 | 적용대상·예외는 안내 링크 제공 |
| 2026과 같은 기준 비교 | 예 | 요율 변화 효과를 분리 |

간편 모드는 세전급여에서 공통 비과세액을 차감한 값을 각 보험 산정기준의 ‘추정 입력’으로 사용한다. 보험별 인정 보수와 신고 기준이 다를 수 있음을 알리고 고급 모드를 제공한다. 동일 값을 실제 모든 보험의 확정 산정기준이라고 설명하지 않는다.

### 고급 모드

- 국민연금 기준소득월액 직접 입력.
- 건강보험 보수월액 직접 입력.
- 고용보험 보험료 산정 보수 직접 입력.
- 장기요양 적용 여부·공식 면제/경감 사례는 검증된 범위만 지원.
- 비교 연도의 기준금액을 따로 입력해 ‘급여 변화 포함 비교’ 가능.
- 실제 지급월의 소득세·지방소득세 직접 입력 옵션.

세금 자동 추정 탭: 부양가족 수는 본인 포함 여부 명시, 자녀는 최신 간이세액표의 나이·요건을 적용한다. 현재 페이지의 ‘20세 이하’ 라벨을 검증 없이 승계하지 않는다. 원천징수 선택 비율을 지원하면 현행 제도의 유효성을 확인한 후 제공한다.

## 6. 계산 엔진 계약

### 6.1 보험별 계산

```text
NP = 국민연금 모듈(기준소득월액, 가입 유형, 적용월, 요율 버전)
HI = 건강보험 모듈(보수월액, 적용월, 상하한·단수 규칙)
LTC = 장기요양 모듈(건강보험료 산정값, 적용월, 연동 비율·단수 규칙)
EI = 고용보험 모듈(인정 보수, 적용월, 가입조건, 요율 버전)
employeeInsurance = NP.employee + HI.employee + LTC.employee + EI.employee
```

각 보험은 법정 산정기준·상하한·부담분·단수 규칙을 별도로 갖는다. 소득에 모든 요율을 더해 한 번 곱한 뒤 반올림하지 않는다.

국민연금은 2번 계산기와 같은 함수와 데이터 버전을 사용한다. 결과에 쓰인 적용기간과 신고 기준을 반환하게 한다.

건강보험은 근로자·사용자 분담과 보수월액 기준 산식을 공단과 법령으로 확인해 구현한다. 연말·보수총액 정산, 보수 외 소득 보험료는 초기 일반 월급 계산에 포함하지 않고 범위를 적는다.

장기요양은 ‘소득 대비 요율’과 ‘건강보험료 대비 비율’을 구분한다. 일반적인 연결 관계는 건강보험료 × (소득 대비 장기요양 요율 / 건강보험 요율)로 설명할 수 있으나, 실제 계산에는 고시 비율과 단계별 단수 규칙을 사용한다. 소득 대비 0.9994%를 건강보험료에 직접 곱하는 오류를 막는다.

고용보험은 근로자 실업급여 부담과 회사의 추가 사업별 부담을 분리한다. 회사 부담을 근로자와 항상 같다고 가정하지 않는다. 요율 변경뿐 아니라 2027 산정기준 변경 여부까지 공식 시행 내용을 확인한다.

산재보험은 근로자 공제 합계에 포함하지 않는다. 회사 부담 기능을 지원하려면 업종별 요율과 적용 특례를 별도 입력·검증해야 한다.

### 6.2 실수령액과 세금

```text
totalDeduction = employeeInsurance + incomeTax + localIncomeTax + supportedOtherDeductions
estimatedTakeHome = grossMonthlyPay - totalDeduction
```

이번 필수 범위에서 기타 회사 공제는 0으로 두고 미포함 항목을 알린다. 비과세 급여는 과세·보수 기준 조정용이며 현금 지급액에서 다시 빼지 않는다.

공식 간이세액표 구현을 검증하지 못했다면 기본 결과는 ‘보험료 공제 후 금액’으로 표시한다. 기존 간이 세금 추정은 별도 보조 결과로 명확히 구분한다. 실수령액 명칭은 세금 반영 범위가 명시되고 실제 기능이 검증된 경우에 사용한다.

세금 표는 적용 시행일·파일·구간·가족 기준을 버전으로 보관한다. 급여 구간 보간이나 연간 세율 단순 적용으로 월 원천징수를 확정 계산했다고 표시하지 않는다. [국세청 근로소득·간이세액표 안내](https://g.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7873&mi=6594)

### 6.3 비교 모드

요율 변화만 비교: 같은 보험별 기준금액에 연도별 규칙 적용. 급여가 바뀐 효과는 포함하지 않는다.

급여 변화 포함 비교: 2026·2027 급여·기준금액을 각각 입력. 증가 원인 설명은 ‘요율만의 효과’라고 단정하지 않는다.

차액은 2027 - 2026으로 통일한다. 공제액의 양수는 부담 증가, 실수령액의 양수는 수령 증가다. 문구와 색을 항목별 의미에 맞춘다. 연 환산은 12개월 동일 조건 가정이며 기간별 실제 연간 합계 기능은 별도다.

모바일에서는 각 항목을 펼칠 수 있는 카드로 만들고 전체 합계가 보이게 한다. 막대차트는 선택 사항이며 표 없이 차트만으로 요율을 전달하지 않는다.

## 8. 교육용 예시와 검수 시나리오

확정 요율 모듈이 모두 검증되기 전에는 그럴듯한 2027 실수령액 예시를 만들지 않는다. 국민연금만 분리한 예시는 동일 기준소득월액 300만원일 때 근로자 월 142,500원→150,000원, 차이 7,500원이다. 전체 보험료 합계의 증가라고 확대하지 않는다.

필수 검수 표:

| 검수 | 기대 동작 |
|---|---|
| 급여 300만원·비과세 0 | 각 보험별 검증된 기준 적용 |
| 급여 300만원·비과세 20만원 | 지급액 300만원 유지, 산정 기준만 해당 규칙에 따라 조정 |
| 비과세 > 급여 | 입력 오류, 결과 확정 표시 안 함 |
| 국민연금 적용 해제 | 해당 공제만 제외, 제외 사유·범위 안내 |
| 상·하한 전후 | 보험별로 독립 적용 |
| 6월→7월 | 기간별 국민연금 설정 선택 |
| 연말→연초 | 각 보험 시행일에 맞는 버전 선택 |
| 건강보험료 대비 장기요양 계산 | 비율 분모·분자와 절사 일치 |
| 고용보험 가정 선택 | 가정 총계가 확정 소계와 구분 |
| 가족·자녀 조건 변경 | 공식 세금 모드에서만 해당 결과 변경 |
| 회사 부담 표시 | 근로자 공제 합계 불변 |
| 2번과 같은 국민연금 입력 | 같은 결과·버전 |
| 잘못된 입력·빈칸 | 기존 결과를 최신처럼 표시하지 않음 |

극단 급여·최고세율 구간·가족 수 경계·원 단위 단수 처리도 표 기반으로 검증한다. 현재 구현 결과를 복제한 테스트가 아니라 공식 표와 독립적인 수기 예시를 기대값으로 사용한다.
