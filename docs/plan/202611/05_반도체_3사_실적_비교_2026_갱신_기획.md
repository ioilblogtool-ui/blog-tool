## 4. 비교의 세 가지 기준

### 4.1 기간

삼성·SK하이닉스는 2026년 3분기 공시의 실제 기간, 마이크론은 편집 시점의 최신 발표 분기를 사용한다. 마이크론 FY Q3를 삼성 달력 Q3와 이름만 맞춰 선택하지 않는다.

각 회사 카드 상단에 ‘2026 Q3 / FY2026 Q4 / 시작일~종료일’을 표기한다. 정확한 기간은 재무제표·10-Q·10-K의 주석 또는 기간 표시에서 가져온다. 연간 누적과 분기 실적을 혼용하지 않는다.

### 4.2 사업 범위

주 비교 패널은 삼성전자·SK하이닉스·마이크론의 연결실적이다. 삼성의 비메모리·스마트폰·가전 포함 범위를 명시하고 메모리 시장점유율이나 기술 경쟁력 순위로 읽지 않도록 한다.

삼성 DS는 기존 segmentRecordIds를 이용한 별도 사업부 표다. DS에는 메모리 외 시스템LSI·파운드리도 포함되므로 ‘메모리 단독 실적’으로 쓰지 않는다. DS를 주 비교로 승격하려면 별도 모드의 검증 계약까지 설계해야 하므로 이번 기본 범위에서는 하지 않는다. 메모리 단독 영업이익은 공개 근거 없이 추정해 채우지 않는다.

### 4.3 회계 기준

국내 기업의 K-IFRS와 마이크론 US GAAP 차이를 표시한다. 마이크론은 GAAP 수치를 메인 표에 우선 사용하고 Non-GAAP는 별도 보조 영역에 둔다. GAAP 영업이익과 Non-GAAP 매출·이익을 섞지 않는다.

다른 기간·범위·회계 기준을 갖는 기업의 공시 수치 비교이지, 완전히 동일 조건의 경쟁력 실험이 아님을 표 주석에서 설명한다.

## 7. 환산·계산 규칙

### 금액 단위

원화 조원 = 원 금액 / 10^12. 달러 billion = 달러 금액 / 10^9. 원문이 million이면 1,000으로 나눠 billion으로 전환한다.

메인 데이터 표에는 원통화를 유지한다. 공통 통화 차트가 필요하면 공인된 환율 출처와 기간 평균 산정법을 선택하고 환산값 배지를 단다. 편집일 현물 환율로 과거 매출을 환산해 공식 실적처럼 표시하지 않는다.

환산 방법 확정 전 첫 배포는 원통화 표 + 영업이익률 공통 차트로 충분하다. 환율 선택을 위해 핵심 배포가 지연되지 않도록 한다.

### 영업이익률과 변화

```text
operatingMargin = operatingIncome / revenue × 100
growthRate = (current - comparablePrior) / comparablePrior × 100
marginChangePp = currentMargin - priorMargin
```

매출이 0이면 이익률은 계산 불가다. 비교 기준 이익이 0·음수이거나 흑자·적자 전환이면 단순 성장률 대신 금액 차이와 ‘흑자전환/적자전환/적자축소’ 등 적절한 표현을 사용한다.

이익률 변화는 %p, 매출 성장률은 %로 구분한다. 원시 수치로 계산한 뒤 마지막 표시 단계에서 반올림한다. 이미 반올림된 조원 금액으로 성장률을 재계산해 원문과 다르게 만들지 않는다.

회사 공식 이익률과 자체 계산값이 조금 다르면 표시 자릿수·원시 금액 기준을 확인한다. 근거 없이 공식 수치를 오류로 단정하지 않는다.

### 비교 기간과 순위

순위를 노출하면 ‘이 표에 포함된 공시 범위·기간 기준’이라고 한정한다. 비동일 기간 원화 환산 매출 순위를 ‘세계 메모리 시장점유율’로 바꾸지 않는다. 시장점유율은 외부 전체 시장 분모와 별도 방법론이 필요한 후속 주제다.

동일 % 단위 막대그래프. 각 막대 이름에 부문·분기를 포함한다. 축은 0을 기준으로 하고 음수가 있으면 음수 영역도 표시한다. 비교 범위와 회계 차이는 차트 아래에 명시한다.

### 선택 차트 2: 각 회사 매출 추이

회사별 원통화 소형 차트 3개 또는 같은 기준 분기를 100으로 둔 지수 차트. 회사마다 서로 다른 분기 라벨을 그대로 사용한다. 지수 차트의 기준 시점과 시작값을 고정하고 원통화 실적 비교와 다른 목적이라고 설명한다.

### 선택 차트 3: 제품별 매출 구성

동일 정의로 공개된 데이터가 있을 때만 만든다. DRAM 안에 HBM이 포함되는 경우 DRAM과 HBM을 별도 배타적 항목처럼 쌓지 않는다. 업체별 미공개 항목을 0으로 넣거나 차액으로 추정해 채우지 않는다.

부적절한 차트: 원과 달러를 같은 단위처럼 같은 축에 놓기, 삼성 전사와 타사 연결을 메모리 매출 순위로 표현하기, GAAP·Non-GAAP 혼합, 연간 capex와 분기 영업이익을 같은 기간 지표처럼 비교하기.

## 10. 분석 문장 작성 규칙

사실: “회사는 이번 분기 ○○를 발표했다.” 숫자·범위·원문 링크 필요.

회사 설명: “회사는 실적 변화의 배경으로 ○○를 제시했다.” 회사 전망을 이미 실현된 사실로 바꾸지 않는다.

편집 해석: “공개된 사업 구성을 고려하면 ○○가 차이에 영향을 미쳤을 가능성이 있다.” 근거를 붙이고 인과를 단정하지 않는다.

금지할 표현: ‘HBM 점유율 확정 1위’(동일 출처·정의 없음), ‘영업이익률이 높으니 무조건 저평가’, ‘성과급 X% 확정’(공식 지급 근거 없음), ‘세 회사 3분기 완전 동일 비교’.

전망 표는 항목 / 회사 발표 내용 / 대상 기간 / 발표일 / 확인 변수로 구성한다. 2027 가이던스가 연간인지 분기인지 명확히 한다. 시장 컨센서스는 출처·기준일·표본이 확보되지 않으면 제외한다.

## 12. 검수 시나리오

- 1,000 million USD가 1 billion USD로 변환되는지 확인한다.
- 원화 조원·억원 변환을 독립 재계산한다.
- 영업이익/매출의 이익률을 재계산하고 표·차트·요약이 일치하는지 확인한다.
- 전년 동기·전분기 비교에 동일 범위·회계 기준을 사용했는지 확인한다.
- 연결 매출과 부문 합계가 내부거래 조정 등으로 다를 때 단순 합산해 오류라고 하지 않는다.
- 마이크론 FY Q4의 연간 누적 매출을 분기 값으로 잘못 수집하지 않는다.
- 숫자 0, 미공개, 해당 없음, 계산 불가를 구분한다.
- 영업이익이 음수·기준 분기 0일 때 성장률이 왜곡되지 않는다.
- 차트 축·라벨·출처·대체 표가 모바일에서 보인다.
- 전망 문장이 실적 요약에 섞여 들어가지 않는다.
- 기존 페이지 수정일과 데이터 기준일을 구분한다.

## 13. 배포·측정·완료 기준

필수 배포 범위: 비교 방법론, 검증된 3사 원통화 표, 영업이익률 차트, 회사별 설명, 출처·기간·회계 기준, 기존 콘텐츠 연결. 환율 환산·제품 구성 그래프는 근거가 부족하면 후속으로 넘긴다.

- [ ] 기존 본문·데이터를 확인하고 변경 이력을 남겼다.
- [ ] 모든 핵심 숫자에 공식 원문과 표 위치가 있다.
- [ ] 뉴스룸과 IR·공시를 대조했다. 차이는 설명 또는 해결했다.
- [ ] 삼성 전사·DS, SK하이닉스 연결, 마이크론 연결을 혼동하지 않는다.
- [ ] 마이크론 분기명과 실제 기간을 표·차트에 표시했다.
- [ ] 메인 지표는 회계 기준이 명시돼 있고 Non-GAAP는 별도다.
- [ ] 원시 단위로 계산하고 최종 표시에서만 반올림했다.
- [ ] 미공개 수치를 0이나 추정치로 채우지 않았다.
- [ ] URL·canonical 유지, 제목·OG·수정일·사이트맵 반영.

지표: 기존 URL 검색 클릭 변화, ‘하이닉스·3사 비교’ 관련 신규 검색어, 비교표·방법론 조회, 관련 콘텐츠 이동. 오래 읽었다는 이유로 비교가 정확하다고 판단하지 않는다.

정정 공시·자료 변경 시 원문과 수정 이력을 갱신한다. 다음 분기가 발표되면 2026 3분기 표를 보존한 상태에서 최신 분기를 추가할지 별도 연도 리포트로 분리할지 결정한다. 검색 편의를 위해 과거 분기 제목을 최신 분기로 조용히 덮어쓰지 않는다.
