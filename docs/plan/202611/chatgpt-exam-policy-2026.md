## 1. 페이지 목적

독자가 자신의 평가 상황에서 ChatGPT를 사용할 수 있는지, 누가 정한 어떤 문서를 확인해야 하는지, 허용되면 무엇을 기록해야 하는지 판단할 수 있게 한다. 저장소의 리포트·도구 등록과 기존 기획·설계에서 동일 슬러그와 주제를 검색했다. 배포된 허브의 FAQ는 대학 시험 허용 범위를 간략히 다루므로, 후속편은 평가 상황별 비교표와 확인·표기 예시로 독립적인 검색 의도에 답한다.

## 4. 섹션 구성

1. **시험 전에 볼 세 가지** — 허용 자료, 인터넷, 생성형 AI. 공지에 AI 사용이 명시되지 않았으면 담당자 확인으로 연결한다.
2. **평가 유형별 비교** — 대학 감독형·온라인·오픈북 시험, 과제·보고서, 논문, 코딩 시험, 국가자격시험, 수능.
3. **허용 범위 읽는 법** — 도구·기능, 사용 시점, 제출물 반영, 사용 내역 제출을 확인한다.
4. **AI 사용 표기 예시** — 허용된 과제에서 도구명·목적·범위를 밝히는 예문과 추가 기록 조건을 보여준다.
5. **기관별 공식 문서·FAQ** — 대학 지침, 종목 공고, 개정일, 관련 리포트 링크를 제공한다.

## 5. 데이터 구조와 판단 기준

평가 행에 평가 유형, 적용 기관·과목·전형, 사용 기능, 시점, 허용 상태, 공개 조건, 확인 주체, 원문 출처와 적용 시점을 기록한다.

| 상태 | 판정 기준 |
|---|---|
| 금지 | 해당 평가나 적용 지침에서 생성형 AI 또는 관련 외부 도구 사용을 금지 |
| 허용 | 평가 공지가 적용 가능한 도구·기능을 명시적으로 허용 |
| 조건부 허용 | 아이디어 정리만 가능하거나, 사용 내역 공개 등 별도 조건이 붙음 |
| 규정 미확인 | 해당 평가의 공개 원문에서 허용 여부를 확인할 수 없음. 수험자에게 적용되는 다른 지침이나 미공개 규정이 있을 수 있음 |

오픈북 여부는 허용 자료 필드에만 기록한다. 예를 들어 교재만 볼 수 있다는 공지는 교재 열람 조건으로 기록하고 생성형 AI에 대한 적용 규정은 따로 확인한다. 강의 공지와 대학 규정의 적용 범위가 충돌하거나 애매하면 공지 원문을 첨부해 담당 교수 또는 시험 운영기관에 서면으로 확인하도록 안내한다.

첫 화면에 오픈북 질문에 대한 답과 확인 순서를 보여준다. 비교표는 평가 유형, 확인할 공지, AI 상태, 허용 조건, 다음 행동을 같은 순서로 제시한다. 모바일에서는 상태와 다음 행동을 읽기 쉽게 배치한다.

3. 승인된 사용에서도 도구명·목적·범위, 인용 검증, 추가 기록 제출 조건을 확인하는 방법.

### FAQ 초안

- **오픈북 시험에서 ChatGPT를 사용해도 되나요?** 오픈북 표시는 열람 가능한 자료의 범위를 알려줍니다. 생성형 AI나 인터넷까지 허용하는지는 시험 안내와 담당자 확인을 통해 판단하세요.
- **AI 금지 문구가 없으면 써도 되나요?** 시험 공지, 강의계획서, 적용되는 대학 지침을 확인하세요. 허용 범위가 명확하지 않다면 어떤 도구와 기능을 쓰려는지 적어 담당자에게 먼저 문의하세요.
- **과제 문장 교정이나 번역도 공개해야 하나요?** 강의가 정한 도구 사용과 공개 조건을 따릅니다. 허용된 경우 도구명, 사용 목적, 적용한 범위를 적고 추가 제출 자료가 있는지 확인하세요.
- **코딩 시험에서 AI 자동완성을 사용해도 되나요?** 공지가 기본 자동완성과 생성형 코드 제안을 어떻게 다루는지 확인하세요. 설치형 확장 기능과 채팅 기능도 평가 운영기관이 허용한 범위에서 사용하세요.
- **논문에 생성형 AI를 사용하면 어디에 밝혀야 하나요?** 소속 기관의 연구윤리 지침과 제출처의 저자 안내를 함께 확인하세요. 허용 범위와 공개 위치는 학위논문 제출 기준이나 학술지 지침에 따릅니다.
- **수능이나 국가자격시험에도 대학의 허용 기준이 적용되나요?** 수능은 해당 학년도 수험생 유의사항을 따릅니다. 국가자격시험은 응시하려는 종목의 시행 공고와 시험장 안내를 확인하세요.
