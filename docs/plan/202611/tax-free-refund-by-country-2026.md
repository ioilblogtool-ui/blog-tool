### 3-2. 실제 환급률

- 이론상 최대 환급률 = 부가세율 ÷ (1 + 부가세율). 예: 프랑스 20% → 16.67%, 일본 10% → 9.09%.
- 실제 환급률은 대행사(Global Blue, Planet 등)·매장·금액 구간에 따라 수수료가 빠져 더 낮다. 예: 프랑스 실환급 약 12% 내외라는 안내가 흔함 → **대행사 공개 환급표를 설계 단계에서 수집**해 "일반적 범위"로만 제시.
- 화면 배지: 이론값은 `계산식`, 실환급 범위는 `추정`. 특정 대행사 수치를 "공식"처럼 쓰지 않는다.

## 5. 계산 로직

```text
포함 부가세 = 구매금액 × r ÷ (1 + r)          (r = 부가세율)
이론 최대 환급액 = 포함 부가세
일반 범위 환급액 = 구매금액 × 국가별 실환급률(하한~상한, 추정)
직접 입력 환급액 = 구매금액 × 사용자 입력 %
원화 환급액 = 환급액(현지통화) × 환율
최소금액 충족 = 구매금액 ≥ 최소금액   (국가별로 세전/세후 기준이 다르므로 데이터에 basis 필드)
부족분 = max(0, 최소금액 − 구매금액)
```

### 검산 예시 (이론값)

| # | 입력 | 기대 결과 |
|---|---|---|
| T1 | 일본, 33,000엔(세금 포함), 표준 10% | 포함 소비세 3,000엔, 이론 환급률 9.09% |
| T2 | 프랑스, 240유로 | 포함 부가세 40유로, 이론 환급률 16.67% |
| T3 | 프랑스, 90유로 | 최소금액 미충족, 10.01유로 부족 |
| T4 | 스페인, 10유로 | 최소금액 없음 → 충족 |
| T5 | 영국 선택 | 계산 비활성 + "관광객 부가세 환급 제도 없음" 안내 |
| T6 | 싱가포르, 109싱가포르달러 | 포함 GST 9싱가포르달러, 최소금액 충족 |

일본 최소금액은 **세전 5,000엔** 기준이므로 T1 계열에서 basis(세전) 비교 로직을 별도 테스트한다(세금 포함 5,400엔 = 세전 약 4,909엔 → 미충족 사례 추가).
