## 2. 기본 범위와 적용대상

초기 지원: 국세청의 국외주식 과세대상 거주 요건에 해당하고, 일반 세율이 적용되는 해외 상장 주식·해외 상장 ETF를 양도한 개인의 단순 사례. 상품 구분·거주 요건을 첫 화면에서 확인한다.

국세청 안내는 일반 국외주식 계산 구조, 국내·국외 과세대상 주식의 손익통산과 기본공제 적용을 설명한다. 상품·세율·거주 요건의 예외는 별도 검토가 필요하다. [국세청 주식 세액계산요령](https://g.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=8800&mi=12274)

일반 모드 제외:

- 국내 상장 해외 ETF, 배당금·이자, 가상자산, 파생상품.
- 일반 국외주식 세율과 다른 주식·특정주식·부동산 관련 기타자산.
- 국내 과세대상 주식과의 혼합 세율 계산, 과세특례·외국납부세액공제.
- 비거주자·단기 거주 등 별도 과세 판단이 필요한 경우.
- 증권사별 취득단가 재구성·거래명세 자동 신고·가산세 계산.

지원하지 않는 조건을 선택하면 일반 22% 계산 결과를 개인 결과처럼 보여주지 않는다. 필요한 신고 자료와 공식 안내 링크를 제공한다.

## 6. 계산 규칙과 수식

배포 전 2026 적용 세법을 재확인한 일반 사례에 다음 계산을 적용한다.

```text
G = 올해 원화 기준 실현이익 합계
L = 올해 원화 기준 실현손실 절대값 합계
F = 손익에 아직 반영하지 않은 적격 필요경비
D = 일반 주식 양도소득 기본공제 2,500,000원
N = G - L - F
B = max(0, N - D)
국세 = B × 20%
지방소득세 = 해당 개인지방소득세 법정 계산 기준 적용
합계 = 국세 + 지방소득세
일반 교육용 근사 합계 = B × 22%
```

국세청의 일반 국외주식 계산 자료는 양도가액에서 취득가액·필요경비를 차감하고 기본공제를 적용한 후 세율을 적용하는 구조를 제공한다. 예외 세율도 있어 범위 제한이 필요하다. [국세청 국외주식 계산 자료](https://taxlaw.nts.go.kr/downloadPDFFile.do?fleId=300000000001047678&fleSn=923559)

구현 원칙:

- 국세 20%와 지방세 2% 상당의 일반 구조를 분리 표시한다. 신고서의 세액 절사·단수 규칙은 별도로 확인한다.
- 22% 일괄 곱셈과 실제 신고 단계별 단수 처리가 다를 수 있으므로 배포 전 검증된 규칙을 사용한다.
- 기본공제는 계좌·증권사별로 중복 적용하지 않는다.
- 전년도 손실을 자동 이월하지 않는다. 일반 모드에 전년 손실 입력란을 만들지 않는다.
- 수수료가 이미 손익에 반영됐다면 F=0이다. 이중 차감을 막는다.
- 사용자가 입력한 평가손익을 실현손익으로 자동 간주하지 않는다.
- 계산은 원화로 수행한다. 달러 수익×현재 환율 방식은 초기 배포에 넣지 않는다.
- 국내·국외 과세대상 주식의 기본공제 공유·손익통산은 설명하되, 혼합 세율 계산은 지원하지 않는다고 표시한다.

시나리오:

```text
N_after = N + scenarioGain - scenarioLoss - scenarioFees
T_before = tax(N)
T_after = tax(N_after)
taxDifference = T_after - T_before
taxReduction = max(0, T_before - T_after)
remainingDeduction = max(0, D - max(0, N))
```

기본공제 잔여액은 신고상 사용 배분의 완전 계산이 아니라 ‘다른 과세대상 주식이 없는 일반 모드의 잔여’로 설명한다. 손실 상태에서는 잔여 공제를 250만원보다 크게 표시하지 않는다. 손실 보전분까지 포함한 추가 이익 허용 범위를 별도로 계산하면 ‘공제 잔여’와 다른 이름을 쓴다.

## 7. 결과 설계

첫 결과: 현재 예상 세액 합계, 국세·지방세 상세, 과세표준, 합산 순손익, 적용 공제.

시나리오 결과: 현재 / 추가 매도 후 / 차이의 3열 비교. 세금이 줄면 ‘예상 세금 X원 감소’, 늘면 ‘예상 세금 X원 증가’, 같으면 ‘현재 조건에서 예상 세금 차이 없음’으로 표시한다.

반드시 함께 보여줄 문구:

- “세금 차이는 매매 수수료·가격 변동·재매수 비용 등을 포함한 투자 손익과 다릅니다.”
- “아직 매도하지 않은 평가손익은 연간 실현손익에 포함하지 않았습니다.”
- “증권사 양도소득 계산 자료의 원화 금액을 기준으로 확인하세요.”

기본공제 아래에 ‘250만원을 넘은 수익 전체에 22%’가 아니라 공제 후 과세표준에 세율을 적용하는 구조를 그림 없이 3행 산식으로 설명한다.

## 9. 연말 일정과 환율 처리

양도시기·귀속연도 판단은 해당 세법과 증권사 연말 안내를 확인해 설명한다. 국가별 휴장·결제 주기·한국 시간 차이가 있어 ‘12월 31일에 팔면 무조건 올해’ 같은 문구를 쓰지 않는다.

초기 버전에는 매도 마감일을 자동 계산하지 않는다. ‘거래 시장의 결제일과 증권사 공지에서 올해 귀속 여부 확인’ 체크리스트를 제공한다. 구체적 날짜를 나중에 넣으면 시장·증권사·시간대·출처·확인일을 함께 표시한다.

달러 입력 확장은 후속이다. 확장 시 취득·양도 시점 환율, 수수료, 매입단가 산정 방식과 거래별 결제일을 설계해야 한다. 현재 환율 하나로 과거 원화 손익을 재구성하지 않는다.

FAQ 문항: 미국주식만 대상인가 / 증권사마다 공제되나 / 평가손실도 공제되나 / 배당도 합산하나 / 국내 상장 해외 ETF를 넣어도 되나 / 작년 손실을 넣어도 되나 / 매도일과 귀속연도는 어떻게 확인하나 / 세금 0이면 신고도 필요 없나 / 환율은 무엇을 쓰나 / 세금 감소액이 투자 이익인가.

‘세금 0이면 신고 불필요’처럼 의무 여부를 계산 결과만으로 단정하지 않는다. 국세청은 국외주식에 대해 확정신고 체계를 안내하므로 최신 신고 안내를 확인해 연결한다. [국세청 주식 신고 안내](https://www.nts.go.kr/nts/na/ntt/selectNttInfo.do?nttSn=1353905)

내부 링크: 투자 계산기·연말정산 체크리스트는 실제 URL 확인 후 연결한다. 급여 연말정산과 해외주식 양도세 신고는 별개 절차임을 링크 설명에 적는다. ‘연말정산 계산기로 해외주식 세금 정산’처럼 오해시키지 않는다.

## 11. 측정·개인정보

핵심 지표: 검색 유입, 계산 완료율, 시나리오 사용률, 출처·신고 안내 클릭률. 시나리오 사용률은 시나리오 계산 사용자/기준 계산 사용자로 집계하되 분모 정의를 고정한다.

입력은 브라우저 내 처리한다. 손익·종목·계좌명·계산 결과는 분석·오류 로그로 전송하지 않는다. 기본은 입력 저장 없음, 페이지 주소만 공유. 새로고침 후 복원은 명시적 선택 기능으로 후속 검토한다.

## 12. 배포 기준과 유지보수

- [ ] 동일 목적 기존 계산기와 중복되지 않는다.
- [ ] 2026 귀속 일반 세율·기본공제·지방세·거주 요건·단수 처리를 공식 근거로 확정했다.
- [ ] 적용대상과 제외 상품이 입력 전후에 일관되게 표시된다.
- [ ] 계좌 합산·수수료 중복·공제 중복·음수 세액 문제가 없다.
- [ ] 시나리오 감소액이 실제 매매 수익으로 오해되지 않는다.
- [ ] 연말 매도 마감일·신고 기한은 최신 공식 안내가 있는 경우에만 확정 표기한다.
- [ ] 5개 대표 사례와 경계값 결과가 맞는다.
- [ ] 금액이 로그·공유 주소로 유출되지 않는다.

12월에는 거래·결제 안내를 재확인한다. 2027년 1월 이후에도 2026 귀속 계산을 유지하고, 5월 신고 시즌에는 준비자료·신고 경로를 업데이트한다. 다음 귀속연도 규칙은 별도 버전으로 추가해 과거 결과를 바꾸지 않는다.
