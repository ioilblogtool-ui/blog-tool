검색량 수치는 확보하지 않았으므로 만들지 않는다. 정성 평가: ① 2026-10-07 국감 보도가 다수 매체에서 동시 노출되어 단기 이슈성이 높음 ② 4개사 모두 대중 인지도 최상위 ③ ‘A vs B’·‘순위’형 비교 검색 의도가 명확함 ④ 분기마다 실적이 나와 반복 갱신 근거가 구조적으로 존재. 이슈가 식은 뒤에도 ③·④가 페이지 가치를 유지한다.

## 1. 페이지 목적

‘패노메논을 위해 4대 기획사가 공동 법인까지 만들었다. 그런데 이 네 회사는 실제로 얼마나 크고, 각각 무엇으로 돈을 버나?’라는 질문에 답하는 상시 비교 리포트다. 페이지 흐름은 **패노메논 → 왜 이 네 회사인가 → 회사 규모 비교 → 아티스트/IP → 수익구조 → 다시 패노메논**이다.

뉴스성 ‘박진영 패노메논 논란 정리’ 페이지로 만들지 않는다. 패노메논 섹션은 입구와 마무리 역할만 하며, 본문 분량의 대부분은 실적·시총·사업구조 비교에 할애한다.

## 5. 계산 로직 또는 데이터 구조

### 기업별 데이터 구조

```ts
type Badge = "공식" | "참고" | "시뮬레이션" | "추정";
interface Sourced<T> { value: T | null; badge: Badge; source: string; url: string; publishedAt: string; period: string; note?: string }

interface AgencyRecord {
  id: "hybe" | "sm" | "jyp" | "yg";
  nameKo: string; listedName: string; market: "KOSPI" | "KOSDAQ"; ticker: string;
  structure: "multi-label" | "single-hq";
  annual: {            // fiscalYear 2025, 연결 기준 고정
    fiscalYear: 2025; basis: "consolidated";
    revenue: Sourced<number>; operatingIncome: Sourced<number>; netIncome: Sourced<number>;
    totalAssets: Sourced<number>; prevRevenue: Sourced<number>; prevOperatingIncome: Sourced<number>;
  };
  latestQuarter: { label: "2026 2Q"; basis: "consolidated"; revenue: Sourced<number>; operatingIncome: Sourced<number>; prevYearOperatingIncome: Sourced<number> };
  market: { asOf: string; closePrice: Sourced<number>; sharesOutstanding: Sourced<number>; marketCap: Sourced<number>; per: Sourced<number | "N/A"> };
  employees: Sourced<number> & { basis: "separate" };
  segments: { name: string; revenue: Sourced<number> }[];   // 사업보고서 부문 그대로
  keyIp: ArtistEntry[];
  strengths: Sourced<string>[]; risks: Sourced<string>[];
}
```

- **기준연도:** 연간 비교는 2025 회계연도만. 2024는 성장률 계산용으로만 보관.
- **연결/별도:** 실적·총자산은 연결, 직원 수는 별도. 표 머리에 기준을 명시한다. 한 표 안에서 기준 혼합 금지.
- **시가총액 기준일:** `asOf`는 단일 영업일 종가(장중 금지). `marketCap = closePrice × sharesOutstanding`(보통주 상장주식수). 직접 계산 시 `시뮬레이션`, 외부 수치 인용 시 `참고`. 4개사 모두 같은 `asOf`가 아니면 순위·KPI를 렌더링하지 않는다(빌드 검증 스크립트로 차단).
- **영업이익률:** `operatingIncome / revenue × 100`, 소수 첫째 자리 반올림. 매출 null이면 null.
- **성장률:** `(당기 - 전기) / |전기| × 100`. 전기 ≤ 0이면 수치 대신 ‘흑자전환’/‘적자전환’/‘적자지속’ 문자열. YG 2025 영업이익은 ‘흑자전환’.
- **시총/매출:** `marketCap / annual.revenue`, 소수 둘째 자리. PER은 순이익 ≤ 0이면 `"N/A"`(적자).
- **순위 계산:** 같은 필드·같은 기간·같은 기준 데이터가 4개사 모두 있을 때만. 하나라도 null이면 해당 KPI는 ‘집계 중’ 표시, 3사 순위로 대체하지 않는다.
- **누락값:** `null` + ‘재확인 필요’. 0으로 치환 금지, 다른 기간 값으로 대체 금지.
- **아티스트 데이터 기준:**
  ```ts
  interface ArtistEntry { name: string; label: string; relation: "본사" | "레이블 자회사" | "자회사"; contractScope: "그룹" | "개인" | "그룹+개인" | "확인 필요"; verifiedAt: string; source: string }
  ```
  각 사 공식 아티스트 페이지에서 구현 시점에 확인한 팀만 기재. 회사당 3~5팀, 최근 실적 보도·사업보고서에서 매출 기여가 언급된 팀 우선. 계약 종료·개인 활동만 별도 계약인 경우 `contractScope`로 구분하고 ‘소속’ 대신 ‘계약 아티스트’ 표현을 쓴다. 이번 조사에서 공식 페이지(hybecorp·jype·ygfamily)는 403/404/500으로 열람 실패했다. 실적 보도에서 확인된 IP는 HYBE–BTS, SM–aespa·NCT, JYP–TWICE·Stray Kids, YG–BLACKPINK·BABYMONSTER·TREASURE이며 이는 **후보**이고 소속·레이블은 공식 페이지 확인 후 확정한다.
- **멀티레이블 처리:** HYBE는 `label` 필드에 레이블명을 쓰고 ‘HYBE 레이블 소속’으로 표기. ‘HYBE 소속’ 단독 표현 금지. 레이블 목록은 HYBE 공식 페이지·사업보고서 종속회사 현황으로 확정(기억 기반 기재 금지). 레이블 간 분쟁 등 법적 쟁점은 이 리포트 범위에서 다루지 않는다.
- **강점/리스크:** 각 항목에 근거(사업보고서 ‘위험 요인’, 실적 수치, 공시)를 `source`로 연결. 팬덤 평가·주관적 평가 금지.

| 리스크 근거 | 신인 투자·비용 증가(실적 발표) | 아티스트 이탈 보도 → 재확인 | 주력 IP 활동 공백 보도 | 소수 IP 의존 → 사업보고서 근거 확인 |

리스크는 사업보고서·공시·실적 발표 문구로 교체·확정한다. ‘군 입대’ 등 개인 신상 관련 표현은 공식 발표가 있는 경우만, 일정 단정 없이 사용한다.

### 6-5. 시총 vs 실적
시총/매출(HYBE 약 2.7배 vs 나머지 1.4~1.5배)을 보여주고, 시총은 과거 실적이 아닌 미래 기대·플랫폼·IP 가치가 반영된다는 일반 설명만 한다. 특정 종목이 고평가/저평가라는 판단과 매수·매도 시사는 금지.

### 6-6. 사업구조
각 사 사업보고서의 매출 구분(음반·음원, 공연, MD·라이선싱, 광고·출연, 기타)을 100% 누적 막대로. 회사마다 분류가 다르므로 원 분류를 보존하고, 공통 카테고리 매핑은 주석으로 공개한다.

### 6-7. 다시 패노메논
‘평소 경쟁하는 4개사가 동일 지분·동일 의결권으로 한 법인을 만든 것은 이례적’ — 구조 사실만. 아래 2열 표로 분리:
- 공식·보도로 확인된 것: 4개사 참여, 동일 자본·의결권, 2027년 12월, 장소, 행사 구성, 정부 지원 범위
- 아직 확인되지 않은 것: 법인명·자본금, 출연 라인업, 중소기획사 참여 방식, 수익 배분, 상표권 귀속 변경 여부

### 6-8. 차트 (3개로 제한)
1. 매출·영업이익 묶음 막대(2025) — 매출 차트와 영업이익 차트를 하나로 합쳐 ‘매출 1위 ≠ 이익 1위’를 한 화면에 보여줌
2. 시가총액 막대(기준일)
3. 영업이익률 막대(2025 vs 2026 2Q 두 계열)

사업구조는 6-6 누적 막대(CSS bar 우선). 표와 같은 수치만 반복하는 차트는 추가하지 않는다. 모바일에서 가로 막대, 4개사 고정 색상(회사 브랜드 색 모방 금지, 사이트 토큰 사용).

### intro 초안 (4단락, 총 600자 이상)

최근 박진영 대중문화교류위원회 공동위원장이 국정감사에 출석하면서 글로벌 K팝 축제 ‘패노메논’이 다시 주목받았습니다. 패노메논은 2027년 12월 개최를 목표로 K팝 공연과 팬덤 시상식, K컬처 전시를 묶은 행사이고, 하이브·SM·JYP·YG가 같은 자본금과 의결권을 가진 전담 법인을 만들어 참여한다고 알려졌습니다. 평소 치열하게 경쟁하는 네 회사가 한 법인에 모였다는 점에서, 이 회사들이 실제로 어느 정도 규모인지 궁금해집니다.

흔히 ‘4대 기획사’로 묶이지만 네 회사의 규모와 체질은 꽤 다릅니다. 하이브는 여러 레이블을 거느린 멀티레이블 구조로 매출과 시가총액이 나머지 회사들과 큰 격차를 보입니다. 반면 2025년 연간 기준으로 영업이익과 영업이익률에서는 SM과 JYP가 앞섰고, YG는 전년 적자에서 흑자로 돌아섰습니다. 같은 이름으로 묶여도 무엇을 기준으로 보느냐에 따라 순위가 달라집니다.

그래서 이 리포트는 시가총액, 매출, 영업이익, 영업이익률을 한 표에 놓고 함께 봅니다. 시가총액은 시장의 기대를, 매출은 사업의 크기를, 영업이익과 이익률은 실제로 남기는 힘을 보여줍니다. 여기에 대표 아티스트와 음반·공연·MD·플랫폼 같은 사업구조를 더하면, 각 회사가 무엇으로 돈을 벌고 어떤 아티스트 활동에 실적이 크게 흔들리는지 이해할 수 있습니다.

비교에는 한계도 있습니다. 실적은 각 회사의 연결 재무제표 기준이라 자회사 실적이 포함되며, 시가총액은 특정 기준일 종가로 계산해 매일 달라집니다. 분기 실적은 월드투어나 컴백 시기에 따라 크게 출렁이므로 연간 실적과 따로 봐야 합니다. 하이브처럼 레이블이 나뉜 회사는 아티스트가 본사가 아닌 레이블에 속해 있다는 점도 함께 확인해 주세요. 이 페이지는 투자 권유가 아닌 공개 자료 비교입니다.

(초안의 순위 서술은 DART 확정치 대조 후 확정한다.)
