## 1. 페이지 목적

### 핵심 질문과 발행 판단

“요즘 K팝 시장은 실제로 얼마나 큰가? 한국에서 얼마나 벌고, 해외에서 얼마나 벌며, 세계 음악시장에서 어느 정도인가?”에 답한다.

단, 이 페이지는 `K팝 시장 = 00조원`이라고 단정하지 않는다. 공공 통계에는 ‘K팝 산업’이라는 단일 분류가 없고, 실제로 존재하는 지표는 콘텐츠산업·음악산업·대중문화예술산업·대중문화예술기획업·음반 수출·글로벌 recorded music처럼 **포함 범위가 서로 다른 숫자**다. 이 차이를 시각적으로 구분해 주는 것이 페이지의 핵심 차별점이다.

검색량 원자료는 확보하지 않았으며 수치로 제시하지 않는다. 검색 수요는 아래 근거로 **정성 평가**한다.

| 판단 근거 | 평가 |
|---|---|
| 질문의 명확성 | ‘K팝 시장 규모’, ‘K팝 매출’은 답이 숫자인 명확한 정보 질문. 데이터형 리포트와 궁합이 좋음 |
| 글로벌 관심도 | 2025년 음악산업이 콘텐츠 11개 장르 중 매출·수출 성장률 1위(동향분석). 해외 공연·데몬헌터스 등 이슈로 관심 지속 |
| 최신 통계 공개 시점 | 2026년 1~7월에 콘텐츠산업조사·대중문화예술 실태조사·IFPI·한류 파급효과 연구가 연달아 공개돼 최신 숫자를 정리할 적기 |
| 기존 콘텐츠 연결성 | 4대 기획사 비교·K팝 수익구조·월드투어 등 파생 콘텐츠의 상위 허브 역할 |
| 상시성 | 매년 같은 통계가 갱신되는 구조라 연도만 바꿔 유지 가능한 에버그린 주제 |

읽은 기준: `CLAUDE.md`, `AGENTS.md`, `CONTENT_GUIDE.md`, `docs/REPORT_CONTENT_GUIDE.md`, `docs/ARCHITECTURE.md`, `docs/QUALITY_SCORE.md`, 최근 기획서 형식(`docs/plan/202610/*`).

**결정:** 같은 검색 의도의 기존 페이지가 없으므로 신규 리포트를 제안한다. 4대 기획사 비교는 아직 존재하지 않으므로 이 페이지는 4사 매출 합계를 **산업 규모와의 단순 비교용 1개 섹션**으로만 다루고, 기업별 상세 비교(아티스트·수익구조·주가·연봉)는 후속 리포트로 남긴다.

| 구분 | K팝 시장 규모 (이번) | 4대 기획사 비교 (후속) |
|---|---|---|
| 단위 | 산업 전체 | 개별 기업 |
| 질문 | 산업이 얼마나 크고 얼마나 커졌나 | 어느 회사가 더 벌고 잘 버나 |

| 4사 데이터 사용 | 합계 1줄 + 산업 대비 참고 비교 | 회사별 매출·이익·부문·아티스트 |

### 3-3. 자료 운영 원칙

1. 확정 통계(A·C)와 잠정 동향(B)을 같은 시계열 선으로 잇지 않는다. 2025는 성장률만 별도 칩으로 표시한다.
2. 언론 보도로만 확인한 수치(B 일부·C·G·H)는 구현 전 원 보고서·DART에서 대조한다. 대조 전에는 배지 `참고`.
3. IFPI 국가 순위(한국 7위 등)는 2차 블로그에서만 확인돼 **이번 기획에서 채택하지 않는다.** IFPI 원문 Top 10 표 확인 시에만 추가한다.
4. 2025년 동향분석의 음악 매출 성장률을 2024 확정값에 곱해 ‘2025 음악산업 15.4조원’ 같은 값을 만들지 않는다(추계 방식이 다름).

## 5. 계산 로직 또는 데이터 구조

### 5-1. 데이터 파일과 필드

`src/data/kpopMarketSize2026.ts` (후속 생성). 모든 통계는 아래 필드를 갖는다.

```ts
type MarketBadge = "공식" | "참고" | "시뮬레이션" | "추정";

type MarketMetric = {
  id: string;            // "music-sales-2024"
  metricName: string;    // "국내 음악산업 매출"
  value: number;         // 원자료 단위 그대로 (예: 1327)
  unit: "백억원" | "억원" | "백만달러" | "억달러" | "명" | "개" | "%";
  displayValue: string;  // "13조 2,700억원"
  year: number;          // 통계 기준연도
  period: "연간" | "분기" | "누적";
  scope: MarketScope;    // 핵심 필드
  source: string;        // "문화체육관광부 콘텐츠산업조사"
  publishedAt: string;   // "2026-02-27"
  url: string;
  badge: MarketBadge;
  status: "확정" | "잠정" | "재확인 필요";
  notes?: string;
};

type MarketScope =
  | "content-industry"      // 콘텐츠산업 11개 장르
  | "music-industry"        // 음악산업 (특수분류)
  | "pop-culture-industry"  // 대중문화예술산업 (기획업+제작업)
  | "agency"                // 대중문화예술기획업
  | "album-export"          // 음반 물품 수출 (관세청)
  | "global-recorded"       // IFPI recorded music
  | "hallyu"                // 한류 전체 파급효과
  | "company";              // 개별 기업 연결 실적
```

`scope`가 다른 레코드끼리는 합산·비율 함수를 호출하지 못하도록, 비율 계산 헬퍼는 `allowedPairs` 화이트리스트(예: `music-industry` ÷ `content-industry` 동일연도)만 허용한다.

| 사용 환율 | 매출·수출 같은 연간 흐름 값은 **해당 통계 연도 연평균 매매기준율**(한국은행 ECOS)을 사용. 연도마다 환율이 다르므로 연도별로 각각 적용 |
| 기록 | 데이터 파일에 `fxRate`, `fxBasis`("2024 연평균"), `fxSource`, `fxCheckedAt` 저장, 화면에 “1달러=○○○원(2024 연평균) 기준 환산” 표기 |
| 금지 | 구현일 현재 환율로 과거 수출액을 환산해 성장률 계산, 원화 환산값끼리 합산 |
| 참고 | 언론의 원화 환산(예: 음악 수출 약 2조 5,797억원)은 매체 임의 환율이므로 그대로 쓰지 않음 |

### 5-6. 누락 데이터 처리

| 누락 | 처리 |
|---|---|
| 2025 음악산업 매출·수출 절대금액 | 동향분석 원문에 있으면 `잠정` 상태로 KPI 보조 표기, 없으면 “2025년 성장률만 공개(+15.8%·+32.4%)” 칩. 2026 콘텐츠산업조사(2025 기준) 발표 시 확정값으로 교체 |

## 6. 결과 화면 방향

- **상단 KPI 4개**: 숫자보다 카드 하단의 `기준연도 · 범위 · 출처 · 배지` 라인을 같은 무게로 노출. 카드 간 단위(원/달러)·연도가 다르다는 점을 상단 한 줄 안내로 고지.
- **범위 다이어그램 (섹션 2)**: 숫자 크기 막대가 아닌 **포함관계 그림** — 콘텐츠산업 ⊃ 음악산업, 대중문화예술산업은 음악산업과 일부 겹치는 원, 세계 recorded music은 별도 축(해외·달러). 모바일에서는 세로 계단형 카드로 전환.
- **차트 1·2**: Chart.js 막대(2019~2024) + 2025 잠정 성장률은 막대가 아닌 텍스트 칩. y축 단위 명시(조원 / 억 달러).
- **차트 3 (선택)**: 범위별 규모 가로 막대를 쓸 경우 차트 제목 바로 아래 “포함 범위가 서로 다른 산업 통계로 직접적인 순위 의미는 없음” 고정 문구. 원/달러 혼합 시 같은 축에 그리지 않는다(원화 지표만 사용).
- **해외 수익 섹션**: 음악산업 수출 / 음반 수출 / 기획업 해외매출 3카드를 “서로 겹치는 범위 — 합산하지 마세요” 띠로 묶음.
- **경제효과 섹션**: 한류 전체 효과 카드에 `한류 전체` 태그를 붙여 K팝 단독 수치로 읽히지 않게 함.
- 모바일 우선: 표는 가로 스크롤 컨테이너, 표 외 가로 넘침 없음.

## 7. SEO 본문 방향

### intro (4단락, 각 150자 이상, 총 600자 이상)

1. **단일 숫자가 없는 이유** — K팝은 세계적으로 흥행하지만 ‘K팝 시장이 몇 조원인가’에 대한 공식 단일 통계는 없다. 정부 통계는 ‘K팝’이 아니라 콘텐츠산업·음악산업·대중문화예술산업처럼 업종 단위로 집계하기 때문에, 어떤 범위를 보느냐에 따라 숫자가 수 배씩 달라진다.
2. **범위 차이** — 국내 음악산업 매출은 2024년 13조원대, 가수·배우·방송인 기획사와 제작사를 함께 보는 대중문화예술산업은 15조원대, 연예기획업만 보면 국내 7.8조원·해외 1.7조원이다. 각 숫자가 무엇을 포함하고 빠뜨리는지 표로 정리한다.
3. **국내·해외·세계를 함께 봐야 하는 이유** — K팝의 성장은 수출에서 더 뚜렷하다. 음악산업 수출은 5년 새 2배 이상 늘었고, 세계 recorded music 시장은 2025년 317억 달러 규모다. 다만 세계 시장 통계는 공연·MD를 빼고 집계해 단순 점유율 계산이 어렵다.
4. **해석 한계** — 확정 통계는 2024년 기준이고 2025년은 잠정 성장률만 공개됐다. 통계마다 기준연도·조사 방식·통화가 다르며, 원화 환산은 연평균 환율 기준 참고값이다. 새 통계가 나오면 갱신한다.

### FAQ 초안 — 9개, 답변 각 2문장 이상

1. **K팝 시장 규모는 몇 조원인가요?** — ‘K팝 시장’만 따로 집계한 공식 통계는 없습니다. 정의가 가장 명확한 국내 음악산업 매출은 2024년 약 13조 2,700억원이며, 범위를 넓힌 대중문화예술산업은 약 15조 3,845억원입니다.
2. **한국 음악산업 매출은 얼마나 되나요?** — 문체부 콘텐츠산업조사 기준 2024년 음악산업 매출은 약 13조 2,700억원으로 전년보다 5.1% 늘었습니다. 2025년은 잠정 동향 기준 15.8% 성장해 콘텐츠 장르 중 가장 높은 증가율을 기록했습니다.
3. **K팝 수출액은 얼마인가요?** — 음악산업 수출은 2024년 18억 145만 달러로 1년 새 47.4% 늘었습니다. 실물 음반 수출만 보면 2025년 약 3억 174만 달러로, 두 숫자는 범위가 달라 더하면 안 됩니다.
4. **K팝은 세계 음악시장에서 어느 정도 규모인가요?** — IFPI 기준 2025년 세계 recorded music 시장은 317억 달러입니다. 이 통계는 공연·MD를 제외하고 국가별 소비 기준이라, K팝의 세계 점유율을 공식적으로 계산한 값은 없습니다.
5. **HYBE·SM·JYP·YG 매출을 합치면 얼마인가요?** — 2025년 연결 기준 4사 매출 합계는 약 5조 1,900억원입니다. 해외 자회사·비음악 매출이 포함된 연결매출이라 국내 음악산업 매출과 단순 비교만 가능하며 시장점유율로 볼 수는 없습니다.
6. **K팝은 음반과 공연 중 어디서 더 많이 버나요?** — 산업 전체의 수익원별 공식 분리 통계는 없습니다. 다만 2025년 음반 수출은 3.4% 늘어난 반면 음악산업 수출은 32.4% 늘어, 공연·디지털 등 음반 외 수익의 비중이 커지는 흐름으로 해석됩니다.
7. **K팝 시장 규모 자료마다 숫자가 다른 이유는 무엇인가요?** — 콘텐츠산업·음악산업·대중문화예술산업·기획업·음반 수출이 각각 다른 범위를 집계하기 때문입니다. 기준연도와 통화(원·달러)도 서로 달라 같은 표에 놓을 때는 범위를 함께 봐야 합니다.
8. **K팝 산업은 매년 얼마나 성장하고 있나요?** — 음악산업 매출은 2019년 약 6조 8,100억원에서 2024년 약 13조 2,700억원으로 약 1.95배가 됐습니다. 같은 기간 수출은 약 2.4배로 매출보다 빠르게 늘었습니다.
9. **K팝이 한국 경제에 미치는 효과는 얼마나 되나요?** — KOCCA 연구에 따르면 한류산업 수출이 1억 달러 늘면 국내 생산유발효과는 약 7,824억원, 연관 소비재 수출은 약 2.02억 달러입니다. 이 수치는 게임·드라마 등을 포함한 한류 전체 기준이며 K팝 단독 효과는 아닙니다.

FAQ의 숫자는 구현 직전 데이터 파일 값과 자동 일치하도록 데이터 파일에서 생성하거나 수동 대조 체크 항목에 넣는다.

## 9. 리스크·주의사항

1. **단일 숫자 단정 금지:** ‘K팝 시장 ○조원’, ‘K팝 전체 수출 ○억 달러’ 표현 금지. Hero·Title·OG 이미지에도 적용.
2. **합산 금지:** 음악산업 수출 + 음반 수출 + 기획업 해외매출 + 한류 소비재 수출을 더하지 않는다(중복·범위 상이).
3. **확정 vs 잠정:** 2024 확정과 2025 동향 추계를 한 시계열로 잇거나 곱하지 않는다.
4. **점유율 금지:** IFPI(공연 제외·국가 소비 기준)와 국내 음악산업(공연 포함·사업체 매출)으로 ‘세계 점유율 ○%’ 계산 금지. 4사 합계 비율은 ‘단순 규모 비교’.
5. **한류 ≠ K팝:** 경제효과 수치는 한류 전체(게임 비중 큼). 섹션·FAQ 모두 명시.
6. **2차 자료 의존:** C·G·H와 B 일부는 언론 보도로 확인. SM 2025 매출은 집계 사이트 기준. 구현 전 원 보고서·DART 대조 필수, 대조 전 배지 `참고`.
7. **IFPI 국가 순위:** 원문 미확인. 2차 자료의 ‘한국 7위’는 연도 혼동 가능성이 있어 사용하지 않는다.
8. **투자 오해:** 엔터주 성장성·매수 판단으로 읽히는 문장 금지. 4사 실적은 산업 규모 맥락으로만.
9. **환율:** 연평균 환율·기준일 미기재 원화값 노출 금지, 원화 합산 금지.
10. **문서 기준 차이:** 프로젝트 일반 Description 권장 길이와 이번 요청(80~120자)이 다르며 이번 요청을 우선했다.
