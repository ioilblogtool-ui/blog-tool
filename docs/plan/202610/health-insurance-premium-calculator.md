0·음수·빈 값·비숫자·무한값을 구분한다. 음수/비숫자는 입력 오류, 빈 값은 입력 요청으로 처리한다. 0원은 자동으로 실제 보험료 0원이라고 단정하지 않고 가입·무보수 상태 확인 안내를 제공한다. 유효 상한을 넘는 입력은 숨겨 잘라내지 말고 상한 적용 사실을 표시한다.

### 지역가입자·퇴직 전환 — 기존 기능 정비 범위

자동차 입력과 추가금 로직을 제거한다. 단순 재산 가액 선형식은 유지하지 않는다. 우선 공단이 산정한 소득월액과 **재산보험료 부과점수**를 받아 계산하는 검증 가능한 경로를 채택한다. 재산 점수는 전체 보험료 점수가 아니므로 소득 보험료를 별도로 더한다. 재산 점수 0도 유효하며 간이 모드로 자동 전환하지 않는다.

연 소득·과표·전월세로 직접 점수를 산정하는 확장 기능은 소득종류별 평가율, 재산 기본공제, 전월세 평가, 재산 등급표, 세대 합산·감면·상하한까지 공식 검증한 뒤 활성화한다. 조건이 부족하면 공단 조회로 연결한다. 기능 유지 범위가 확정되면 Description에 지역가입자 기능을 추가하되 80~120자를 다시 검증한다.

퇴직 전환 비교는 수정된 지역 계산을 공유한다. 임의계속가입액을 퇴직 직전 월급만으로 산출하는 기존 방식은 정확한 금액처럼 제공하지 않는다. 최근 보수 기준·자격·신청기한을 확인한 별도 시나리오 또는 사용자가 확인한 월 납부액 입력으로 비교하고, 피부양자 자격을 자동 확정하지 않는다.

페이지 순서: 입력 → 월 공제 합계 → 건강/장기요양 분리 → 근로자/회사 비교 → 연간 부담 → 동일 보수 2026/2027 → 보수 인상 비교 → 상세 산식 → 관련 도구·SEO·FAQ.

## 5. 계산 로직 또는 데이터 구조

### 일반 직장가입자

`B`는 월 보수월액, `h_y`는 해당 연도 건강보험료율, `l_y`는 소득 대비 장기요양보험료율이다. 감면·정산이 없는 일반 근로자 기준이다.

```text
연봉 입력 B = (연봉 - 확인된 산정 제외 연간 급여) / 12
절사 전 전체 건강보험료 = B × h_y
절사 전 근로자 건강보험료 = 전체 건강보험료 × 50%
절사 전 회사 건강보험료 = 전체 건강보험료 × 50%
장기요양보험료 = 해당 부담자의 건강보험료 × (l_y / h_y)
근로자 월 공제 합계 = 근로자 건강보험료 + 근로자 장기요양보험료
회사 월 합계 = 회사 건강보험료 + 회사 장기요양보험료
연간 부담 = 해당 월 합계 × 12
보수 대비 본인 보험료 비율 = 근로자 월 합계 / B × 100 (B > 0)
```

2027 `h=0.0719`, 근로자·회사 각 `0.03595`는 확정이다. `l_2027`은 미확인이므로 장기요양·총합·합계 비율은 확정 계산할 수 없다. 미확인 상태를 0원으로 표시하지 않는다. 정식 2027 전체 계산기 공개는 해당 값과 상하한·단수처리 검증 후 진행한다.

기존 구현은 부담자별 건강보험료를 10원 미만 절사하고, 그 금액에 13.14%를 곱한 장기요양도 10원 미만 절사한다. 이 처리는 **기존 회귀 비교용 규칙**이며 이번 조사만으로 공식 단수처리로 확정하지 않는다. 구현 전에 공단 계산·징수 기준으로 절사 시점과 `0.9448/7.19` 대 `13.14%` 표시비율 적용을 결정한다. 표시용 반올림 비율을 원 산식 대신 무조건 쓰지 않는다. 전체 합산 결과는 실제 부담자별 처리 후 합으로 정의하고 이론값과 구분한다.

상하한은 전체 보험료 기준과 본인 부담 기준을 구분해 적용하고, 건강과 장기요양 상한을 혼용하지 않는다. 연간값은 12개월 동일 보수의 시뮬레이션이며 정산·중도 입퇴사 금액이 아니다.

건강보험 요율 효과는 상하한·감면 등 조건이 같고 일반 범위의 동일 보수라면 0원이다. 장기요양 요율과 상하한까지 확인하기 전에 “총보험료가 그대로”라고 쓰지 않는다. 실수령 영향은 “건강보험 관련 공제 증가액”으로 표시하며 전체 실수령 변화는 4대보험·연봉 계산기로 안내한다.

### 지역·보수 외 소득

지역 건강보험료의 기본 구조는 `공단 산정 소득월액 × h + 재산 부과점수 × 211.5원`이다. 저소득 기준·상하한·감면을 별도 처리한다. 기존 `재산 × 0.0000015`와 `자동차 4천만원 이상이면 25,000원`은 폐기 대상이다. 기존 직접 점수 모드의 `점수 × 211.5`만으로 전체 지역 보험료를 만드는 방식도 수정한다.

보수 외 소득 추가보험료는 회사와 반씩 나누는 보수월액보험료와 구분한다. 종류별 평가·공제 순서를 검증하지 않은 단일 연 소득 입력은 금액 산출에 사용하지 않으며, 별도 납부 가능성을 안내한다. 추후 계산을 추가하면 본인 전액 부담과 급여명세서 공제액 밖의 납부액을 구분한다.

### 대표 예시 — 확정 가능한 건강보험 이론값

## 6. 결과 화면 방향

첫 카드에는 **월 건강보험 관련 공제 합계(본인)**를 가장 크게 보여준다. 바로 아래 본인 건강보험·장기요양·연간 합계 카드를 제공한다. 회사 부담은 “회사가 별도로 부담하는 금액”으로 표시한다. 지역 모드에서는 월 납부액, 퇴직 모드에서는 전환 전후 차이로 제목을 바꾸고 근로자 공제 표현을 재사용하지 않는다.

공식 요율 안내: “2027 건강보험료율 7.19% — 2026년과 동일”. 비교 안내: “보험료율은 동결됐지만, 연봉이나 보수월액이 올랐다면 실제 건강보험료는 늘어날 수 있습니다.” 같은 보수 비교와 실제 보수 변경 비교에 각각 가정을 표시한다.

직장 결과·회사 결과 모두 `시뮬레이션`으로 표시한다. 기존 `official` 결과 배지를 그대로 유지하지 않는다. 지역의 단순 가정은 `추정`, 검증된 산식에 입력한 결과는 `시뮬레이션`으로 구분한다. 공단 고지·급여명세서가 최종 확인 경로다.

모바일 320~768px에서 입력→결과 순서, 카드 세로 배치, 표 스크롤 래퍼, 키보드 조작·레이블·선택 상태·결과 알림을 확인한다. 실시간 계산·초기화·복사 링크를 유지하며 월급/연봉 모드, 비교 연도·이전 급여, 지역 모드·퇴직 조건까지 URL 복원한다. 연봉 등 입력이 공유 URL에 포함됨을 복사 동작 근처에서 알린다.

3. **건강보험료율이 동결됐는데 왜 보험료가 올랐나요?** 연봉이나 회사가 신고한 보수월액이 늘면 같은 비율을 적용해도 부담 금액이 증가할 수 있습니다. 정산·감면 변화 등이 포함됐는지는 급여명세서와 공단 고지 내역을 함께 확인하세요.
4. **월 보수 300만원이면 건강보험료가 얼마인가요?** 감면·정산이 없고 일반 범위라는 가정에서 본인 건강보험료는 월 107,850원입니다. 장기요양보험료는 별도이므로 해당 연도 확정 기준으로 계산한 금액을 더해야 월 공제 합계를 알 수 있습니다.
5. **연봉 5천만원이면 건강보험료가 얼마인가요?** 산정 제외 급여 없이 연봉을 12로 나누면 본인 건강보험료 이론값은 월 약 149,792원입니다. 이는 단수처리 전 값이며 실제 신고 보수월액·제외 항목·정산에 따라 달라질 수 있습니다.
6. **건강보험료는 회사와 직원이 절반씩 내나요?** 일반 직장가입자의 보수월액보험료는 근로자와 회사가 절반씩 부담합니다. 보수 외 소득월액보험료와 공무원·사립학교 교원 등 부담 구조가 다른 대상은 이 설명과 구분해야 합니다.
7. **장기요양보험료는 어떻게 계산하나요?** 건강보험료에 해당 연도 장기요양보험료율과 건강보험료율의 비율을 적용합니다. 2027 확정 요율은 구현 전 재확인이 필요하며 2026의 안내 비율 13.14%를 그대로 2027 기준으로 쓰면 안 됩니다. 이 답변은 공개 전에 확정 산식과 수치로 갱신합니다.
8. **성과급에도 건강보험료가 붙나요?** 근로 대가로 지급하는 상여 등 보수에 포함되는 금품은 보험료 산정에 반영될 수 있습니다. 지급 시점과 보수 신고·정산 방식에 따라 공제 시점이 달라질 수 있으므로 회사 급여 담당자와 신고 내역을 확인하세요. 적용 근거는 S4에 연결된 시행령 제33조의 최신 적용본으로 대조합니다.
9. **직장가입자도 다른 소득이 있으면 더 내나요?** 보수 외 소득이 연 2,000만원을 초과하면 별도 소득월액보험료 대상이 될 수 있습니다. 소득 종류별 평가 방식이 달라 단일 총액만으로 정확한 추가액을 계산하기 어렵고, 이 페이지의 기본 월급 공제 결과에 자동 합산하지 않습니다.
10. **퇴사하면 건강보험료가 왜 비싸지나요?** 직장가입자가 회사와 분담하던 방식에서 지역가입자로 전환되면 소득과 재산을 기준으로 세대 보험료를 내게 될 수 있습니다. 피부양자나 임의계속가입 조건을 충족하는지에 따라 달라지므로 퇴사하면 반드시 비싸진다고 단정할 수 없습니다.
11. **지역가입자 건강보험료는 어떻게 계산하나요?** 소득 보험료와 재산 부과점수에 따른 보험료를 합산하는 구조이며 자동차 부과는 폐지됐습니다. 소득평가·세대·감면·상하한에 따라 달라지므로 재산 점수만 곱한 값을 전체 보험료로 읽지 말고 공단 고지서와 비교하세요.

## 9. 리스크·주의사항

- 건강 동결을 건강+장기요양 합계 동결로 확대 해석하지 않는다.
- 2027 장기요양·상하한·단수처리·지역 산식 미확인 항목을 이전 연도 값으로 채우지 않는다. 확정 숫자를 얻을 수 없는 항목은 문서에 재확인 대상으로 남긴다.
- 기존 지역 계산은 단순 참고값이어도 폐지된 자동차 부과·근거 없는 재산 비율을 계속 제공할 수 없다. 올바른 산식 또는 공단 조회 경로로 바꾼다.
- “공식 요율”과 “사용자 입력 계산 결과”는 다르다. 기존 본인·회사·퇴직 전 결과의 공식 배지를 시뮬레이션으로 교체한다.
- 공무원·사립학교 교원·국외 근무·감면·정산·중도 입퇴사 등은 일반 근로자 산식의 적용 범위 밖으로 안내한다.
- 소득세상 비과세와 건강보험 보수 제외를 무조건 동일시하지 않는다. 보너스 중복 입력과 연봉/월급 전환 시 이중 차감을 막는다.
- 공유 URL의 기존 입력 호환성을 확인하고 허용된 모드·유한한 숫자·범위를 검증한다. 사용자 원문을 `innerHTML`에 넣지 않고 개인정보를 서버로 전송하지 않는다.
- 사용자가 요청한 산식·예시·경계값 확정 중 공식 발표를 확인하지 못한 부분은 확정하지 않았다. 이 문서는 개발 범위를 전달할 수 있으나 모든 2027 금액을 즉시 구현할 수 있는 확정 데이터 문서는 아니다.
