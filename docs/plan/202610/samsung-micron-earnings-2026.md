## 1. 페이지 목적

### 핵심 질문과 발행 판단

“삼성전자와 마이크론은 최신 분기에 얼마나 벌었고, 왜 차이가 나며, HBM 경쟁과 직원 성과급에는 어떤 의미가 있나?”에 답한다. 발표 숫자, 재계산 지표, 회사 설명, 편집 해석을 분리한다. 순위만 매기는 기사보다 비교 기준을 이해시키는 리포트를 지향한다.

초기에는 삼성전자 2026년 3분기 잠정실적과 마이크론 FY2026 4분기 공식 실적을 다룬다. 삼성전자 확정실적과 SK하이닉스 발표는 같은 페이지에 순차 반영한다. 2026년 이후에는 기존 기간 자료를 보존하고, 연도 변경 페이지 여부를 별도 기획한다.

### 기존 콘텐츠 중복 점검

`src/pages`와 `src/data` 전체를 요청한 10개 키워드(삼성전자 실적, 삼성전자 3분기 실적, 마이크론 실적, SK하이닉스 실적, 삼성전자 SK하이닉스, 반도체 실적, HBM, 반도체 전망, 삼성전자 성과급, SK하이닉스 성과급)로 검색했다. 등록 메타와 `docs/sheets/page_inventory_2026-10-07.csv`를 함께 대조했다. 문자열 검색은 관련 후보 수집용이며, 표현이 다른 페이지까지 메타·데이터의 질문과 기간으로 판단했다.

삼성전자 수치와 공식 증감률의 출처는 [한국 뉴스룸 잠정실적](https://news.samsung.com/kr/삼성전자-2026년-3분기-잠정실적-발표), 비교 분기 원값은 [글로벌 뉴스룸](https://news.samsung.com/global/samsung-electronics-announces-earnings-guidance-for-third-quarter-2026)이다. 삼성전자의 DS·메모리·파운드리·MX 수치는 해당 잠정 발표에 없다. 원인은 확정실적에서 확인하고 외부 사업부 추정을 연결 공식값으로 넣지 않는다.

마이크론 금액·분기 종료일은 [FY2026 Q4 공식 발표 재무표](https://investors.micron.com/news/press-release/2026/Micron-Technology-Inc--Reports-Record-Fiscal-Fourth-Quarter-and-Full-Year-2026-Results/default.aspx)에 근거한다. 시작일은 직전 종료일의 다음 날로 정리했다. 해당 분기는 14주이며 달력상 7~9월과 일치하지 않는다. 추가 주가 있는 회계연도라는 점은 [FY2026 Q2 공식 설명](https://investors.micron.com/static-files/e089f8c0-065d-47b8-9d02-bfa863cdb357)에서도 확인된다.

마이크론 공식표의 GAAP 이익률 80.7%는 `공식`으로, 같은 금액을 직접 나눈 결과는 `시뮬레이션`으로 구분할 수 있다. 본문 KPI는 재계산 지표로 통일한다. 매출총이익률을 영업이익률로 잘못 쓰지 않는다. Non-GAAP는 부가 설명에서만 별도 표기하고 기본 비교표에 섞지 않는다.

### 3-3. HBM 확인 범위

| 제품 | 삼성전자 공식 근거 | 마이크론 공식 근거 |
|---|---|---|
| HBM3E | [2026-03-18 AMD 협력 발표](https://news.samsung.com/global/samsung-and-amd-expand-strategic-collaboration-on-next-generation-ai-memory-solutions)의 공급 관계 | 최신 Q4 준비자료에서 별도 수량·매출 미확인. 이전 세대 현황은 발행 전 공식 자료 추가 확인 |
| HBM4 | [HBM4 양산 출하 발표](https://news.samsung.com/kr/삼성전자-세계-최초-업계-최고-성능의-hbm4-양산-출하) | Q4 준비자료의 확대 언급. 구체 고객·물량은 원문 공개 범위만 사용 |

샘플·인증·양산·고객 협력·매출 인식은 서로 다른 단계다. 공식 발표일과 당시 상태를 병기하고, 최신 Q3 이익에 대한 직접 기여의 증거로 취급하지 않는다. 후속 자료에서 상태가 바뀌었는지는 발행 직전 재확인한다.

자료 우선순위는 기업 IR·뉴스룸·공시→외부 분석 순서다. 모든 금액과 코멘트에 `sourceId`, 원문 URL, 발표일, 확인일을 연결한다. 외부 분석은 `참고`, 편집 추산은 `추정`, 계산 결과는 `시뮬레이션`을 사용한다. 배지는 `공식 / 참고 / 시뮬레이션 / 추정` 네 종류만 사용하며, “잠정·확정·미공개·가이던스”는 설명 문구로 처리한다.

## 5. 계산 로직 또는 데이터 구조

### 5-1. 데이터 항목

다음은 설계 단계에 전달할 구조 요구사항이다. 실제 TypeScript·UI 구현을 완료한 상태는 아니다.

```ts
type DataBadge = '공식' | '참고' | '시뮬레이션' | '추정';
type CompanyId = 'samsung' | 'micron' | 'skhynix';
type Metric = {
  value: number | null;
  badge: DataBadge | null; // 미공개면 값·배지 모두 null
  sourceId: string | null;
  note?: string;
};
type QuarterRecord = {
  id: string; // company + fiscalYear + fiscalQuarter + scope + basis
  companyId: CompanyId;
  periodLabel: string;
  fiscalYear: number;
  fiscalQuarter: 1 | 2 | 3 | 4;
  periodStart: string;
  periodEnd: string;
  weeks?: number;
  currency: 'KRW' | 'USD';
  unit: 'trillion' | 'million';
  scope: 'consolidated' | 'DS' | 'memory';
  basis: 'K-IFRS' | 'US-GAAP' | 'non-GAAP';
  releaseStatus: 'preliminary' | 'reported';
  auditStatus: 'unaudited' | 'reviewed' | 'audited' | 'unknown';
  releasedAt: string;
  checkedAt: string;
  revenue: Metric;
  operatingProfit: Metric;
  netIncome: Metric;
  reportedMargin?: Metric;
  previousQuarterId: string | null;
  previousYearQuarterId: string | null;
};
```

같은 회사의 과거 분기를 별도 레코드로 보존한다. 성장률은 각 레코드의 직전 분기·전년동기 ID를 참조해 계산한다.

갱신 메타에는 `updatedAt`, 비교 스냅샷에는 `snapshotId`·대상 레코드 ID 목록·갱신 이유·발표 상태를 저장한다. `sourceId`는 출처 표(URL·원자료 단위·페이지/항목·발표일·확인일)를 참조한다. 공식 코멘트·제품 상태·가이던스는 실적 레코드와 별도 배열로 관리한다.

### 5-2. 기준기간·비교 기준

- 비교 이름은 “최신 발표 기준”이다. 표의 회사별 열 제목에 공식 분기 명칭과 실제 대상기간을 함께 표시한다.
- 기본 비교는 연결 K-IFRS vs 연결 US-GAAP. 회계기준 차이까지 해소한 조정 비교는 아니다.
- 마이크론 FY2026 Q4의 14주와 삼성전자 달력 분기 차이는 표 바로 위에 안내한다. 매출을 일수로 나누어 같은 기간 실적처럼 재구성하지 않는다.
- 회사별 전분기·전년동기는 각 회사의 공식 회계기간을 사용한다. 동일 범위·통화·기준의 실적끼리 계산한다.
- 삼성전자 확정실적 갱신은 최신 표의 잠정값을 대체하되 잠정 발표 기록·변경 이유를 보존한다. 성장률의 비교 기반이 수정되면 함께 갱신한다.

### 5-3. 산식·표시

```text
영업이익률(%) = 영업이익 / 매출 × 100
전년동기 증가율(%) = (현재 값 / 전년동기 값 - 1) × 100
전분기 증가율(%) = (현재 값 / 직전 분기 값 - 1) × 100
이익률 차이(%p) = 회사 A 영업이익률 - 회사 B 영업이익률
원화 참고 금액 = 달러 원자료 × 원/달러 적용 환율
백만 달러를 조 원으로 환산 = 백만 달러 값 × 환율 / 1,000,000
```

원자료 정밀도를 유지하고 표시 단계에서 이익률 소수점 1자리, 재계산 성장률 2자리로 반올림한다. 요청한 이익률·성장률 검산을 위해 일반 가이드의 정수 표시보다 상세 정밀도를 적용한다. 공식 발표 증가율은 발표값 그대로 보존하고 재계산 값과 섞지 않는다. 삼성전자 공개 비교값은 반올림되어 있으므로 공식 증가율과 재계산 결과가 일부 다를 수 있다.

매출이 0·미공개이면 이익률은 “계산 불가”. 비교 분기 값이 0·음수·미공개이면 통상 증가율 대신 “계산 불가”, “흑자 전환”, “적자 지속” 등 실제 부호에 맞는 문구를 사용한다. 미공개를 0으로 입력하지 않는다. 차트에도 미공개 막대를 그리지 않는다.

### 5-4. 환율 처리

초기 발행의 기본 표는 삼성전자 조 원, 마이크론 억 달러 또는 백만 달러를 명확히 표시한다. 원화 환산 없이 이익률·성장률을 비교할 수 있다. 절대 영업이익의 원화 차액·배수는 환율이 없으면 표시하지 않는다.

환산을 추가하려면 검증한 환율 출처·기준일·종류(고시 환율 또는 기간 평균)와 사용값을 필수 기록한다. 예시 환율을 오늘의 공식 환율로 기록하지 않는다. 두 실적을 같은 참고 환율로 환산하는 것은 경제적 동일 기간 비교가 아니므로 `시뮬레이션`과 “분기 실제 환산 실적이 아닌 참고 환산”을 표시한다. 사용자 입력은 유한한 양수만 허용하고 원자료는 유지한다. 이번 기획서에서는 환율을 확정하지 않았다.

### 5-5. SK하이닉스 확장

회사 목록과 실적 레코드 목록을 분리한다. 초기 비교 ID는 삼성전자 Q3·마이크론 FY2026 Q4 두 개다. SK하이닉스는 회사 목록에만 대기 상태로 두고 수치 레코드는 발표 후 추가한다.

발표 후 기간·연결 기준·회계기준·출처를 검증한 레코드를 삽입하면 비교표의 회사 열이 3개로 늘어난다. 성과급 계산을 여기에 붙이지 않는다. 삼성전자 DS 표도 연결 표와 분리한다. 마이크론 다음 분기 갱신 시 삼성전자·SK하이닉스는 기존 최신 기간을 유지하고 회사별 기간을 강조한다. Q3 비교 스냅샷은 보존한다.

## 6. 결과 화면 방향

- Hero와 InfoNotice에 “삼성전자 잠정 연결 / 마이크론 GAAP / 기준기간 다름”을 짧게 고지한다.
- KPI 4개에 회사·분기·통화·공식 배지를 표시하고 이익률 보조 행에는 `시뮬레이션`을 표시한다. 6개 카드로 정보량을 늘리지 않는다.
- 핵심 비교표는 상단 배치. 모바일 표 전용 스크롤 래퍼, 본문 전체 가로 넘침 방지, 스크롤 가능 안내를 적용한다.
- 이익률의 높고 낮음은 비교하되 “마이크론이 기업 경쟁력에서 우위”라는 결론으로 바꾸지 않는다. 삼성전자는 메모리·파운드리·모바일·가전·디스플레이 등 사업을 포함한다.
- 시각화는 회사별 과거→직전→현재의 원통화 추이를 우선한다. 매출과 영업이익의 단위를 통일하고 영업이익률은 별도 표시한다. 서로 다른 통화의 절대 금액을 하나의 막대 순위로 그리지 않는다.
- 3사 발표 후 이익률 비교 막대는 가능하다. CSS bar 우선, 정확한 숫자표를 함께 제공한다. 차트가 없어도 핵심 비교가 성립해야 한다.
- 성과급 CTA: “그래서 삼성전자·SK하이닉스 직원 성과급은 얼마나 달라질까?” 아래 산정 차이 안내와 관련 리포트 두 개를 제공한다.
- 마지막 갱신일과 회사별 발표일, 변경 내역을 표시한다. 사용자 화면에 구현 계획·데이터 모델 설명을 노출하지 않는다.

## 7. SEO 본문 방향

메인 키워드를 Title·H1·첫 문단에 자연스럽게 배치한다. 첫 방문자가 최신 분기와 비교 한계를 바로 이해하도록 한다. 인트로는 4단락 이상, 각 150자 이상, 전체 600자 이상으로 작성한다. 아래는 수치 반복을 줄인 방향 초안이며 발행 전 길이와 최신 사실을 검수한다.

1. **발표 맥락:** 삼성전자 2026년 3분기 잠정실적은 이번 분기에 회사 전체가 얼마나 벌었는지 먼저 확인하는 자료입니다. 실적 발표 직후에는 매출과 영업이익 숫자뿐 아니라 지난해 같은 분기와 직전 분기보다 얼마나 달라졌는지 함께 살펴볼 필요가 있습니다. 이 리포트는 공식 연결실적을 출발점으로 삼고, 아직 결산을 마치지 않은 잠정 발표라는 점과 사업부별 설명이 추가될 시점을 구분해 안내합니다.
2. **비교 이유:** 마이크론 최신 실적을 함께 보면 한국과 미국의 주요 메모리 기업이 각자의 최근 발표에서 어떤 수익성을 보여주었는지 살펴볼 수 있습니다. 매출과 영업이익은 원통화로 읽고, 영업이익률은 같은 나눗셈으로 계산해 규모와 수익성을 구분합니다. 마이크론 회계연도의 분기 명칭과 실제 시작일·종료일을 함께 표시하며, 두 기업의 실적이 완전히 같은 기간의 결과라는 오해를 줄입니다.
3. **실적 메커니즘:** AI 서버와 가속기는 데이터를 빠르게 전달할 메모리와 저장장치를 필요로 합니다. 다만 AI 수요가 늘었다는 설명만으로 한 회사의 이익 증가를 모두 설명할 수는 없습니다. 제품 가격, 출하량, 고부가 제품 비중과 비용을 함께 읽어야 하며, 이 리포트는 회사가 공식 자료에서 공개한 변화와 편집 해석을 구분합니다. HBM 양산이나 고객 협력 발표도 해당 분기의 이익 기여액이 공개된 것과는 다르게 해석해야 합니다.
4. **한계·다음 행동:** 삼성전자는 반도체 외에도 여러 전자 사업을 포함하고, 마이크론은 메모리와 저장장치 중심의 기업입니다. 그래서 전체 회사의 영업이익률 차이만으로 메모리 기술 경쟁력이나 투자 성과를 단정할 수 없습니다. 삼성전자 확정실적과 SK하이닉스 발표가 나오면 비교 범위를 보강하고, 직원 성과급은 회사별 별도 기준을 확인하도록 관련 리포트로 연결합니다. 분기 영업이익의 증가율을 개인의 성과급 증가율로 그대로 적용하지 않습니다.

## 9. 리스크·주의사항

1. **잠정과 확정:** 공식 회사 발표라도 잠정치는 확정치가 아니다. 확정 발표 전 DS·메모리·파운드리·MX 이익을 공식값처럼 채우지 않는다.
2. **기간:** 삼성전자 2026 Q3와 마이크론 FY2026 Q4는 겹치는 일부 기간이 있지만 동일 분기가 아니다. 마이크론의 추가 주까지 안내한다.
3. **회계·지표:** K-IFRS·GAAP 차이, 연결·사업부 범위, 영업이익·순이익·매출총이익률을 구분한다. Non-GAAP 이익으로 비교 순위를 바꾸지 않는다.
4. **실적 원인:** 발표된 회사 코멘트와 그에 대한 편집 해석을 구분한다. HBM 기술 발표를 그 분기의 이익 기여 수치로 전환하지 않는다.
5. **사업구조:** 삼성전자 전체와 메모리 중심 기업의 이익률로 메모리 경쟁력을 단정하지 않는다. DS에 비메모리 사업도 포함됨을 명시한다.
6. **성과급:** OPI·TAI·PS의 기준급·산정기간·사업부·지급방식이 다르다. 실적 증가율과 지급률의 동일 비례를 주장하지 않는다.
7. **환율·예측:** 환율 미확정 시 원화 차액 비교를 하지 않는다. 다음 분기 가이던스와 SK하이닉스 예상치는 실현 실적과 분리한다.
8. **기존 콘텐츠:** 내부 페이지의 전망·추정 모델을 최신 공식 실적 출처로 역인용하지 않는다. 특히 기존 배지 종류를 이 페이지에 그대로 가져오지 않는다.
9. **광고·출처:** 초기 제휴 0개. 외부 출처 링크는 새 탭일 때 `noopener noreferrer`, 제휴를 나중에 추가하면 별도 고지·정책 준수. 금융 콘텐츠의 결론을 매수 권유나 확정 수익 약속으로 쓰지 않는다.
10. **범위:** 프로젝트 문서마다 메타 길이·표시 정밀도·스타일 기준에 일부 차이가 있다. 이번 명시 요청을 우선하고, 실제 스타일은 설계 단계에서 기존 공통 컴포넌트·토큰 사용 현황을 확인한다.
