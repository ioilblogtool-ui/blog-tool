## 1. 페이지 목적 및 기획 배경

### 1-1. 왜 지금인가

- 한국은행은 2026-07-16(2.50% → 2.75%), 2026-08-27(2.75% → 3.00%) 두 차례 연속으로 기준금리를 인상했다. 현재 기준금리는 **연 3.00%** `공식`.
- 다음 통화정책방향 결정회의는 **2026-10-22(목)** 로 한국은행 공식 일정에 게재되어 있다 `공식`. 결정 전후로 "기준금리 오르면 대출이자", "금리 0.25 오르면 이자 얼마" 류 검색이 집중될 것으로 본다.
- 최근 방향이 '인상'이므로, 인하만 가정한 콘텐츠("금리 인하 수혜")가 아니라 **인상·인하 양방향**을 같은 비중으로 다룬다.

### 1-2. 무엇을 해결하나

사용자가 실제로 궁금한 것은 한국은행 기준금리 숫자가 아니라 "**내 대출금리가 바뀌면 내 월 납입액이 얼마나 바뀌나**"다. 따라서 이 계산기는:

1. 기준금리 → 대출금리 **자동 연동을 하지 않는다**.
2. 사용자가 **현재 대출금리**와 **변경 후 예상 대출금리**(또는 ±변동폭)를 직접 입력한다.
3. 같은 잔액·같은 남은 기간·같은 상환방식에서 두 금리의 월 상환액·총이자를 비교한다.
4. ±0.25%p / ±0.5%p / ±1.0%p 빠른 비교표로 "얼마나 민감한지"를 한눈에 보여준다.

### 1-3. 뉴스성이 아닌 상시 계산기로 설계

- 금통위 결정 내용은 상단 InfoNotice + "최근 기준금리 결정" 카드 1개로만 노출하고, 계산 로직은 기준금리와 독립.
- 기준금리·결정일·다음 회의일은 데이터 파일 1곳(`loanRateChange.ts` 가칭)의 상수로 관리 → 결정 후 숫자만 갱신.
- Title·H1에 특정 회의 날짜를 넣지 않는다(연도 `2026`만 포함).

### 2-3. 코드 재사용 방침

`loan-refinancing-calculator.js` 의 `calculateMonthlyPayment`·`calculateTotalInterest` 와 동일한 공식을 사용한다. 설계 단계에서 공통 유틸(`public/scripts/` 내) 분리 여부를 결정하되, 기존 페이지 동작을 바꾸는 리팩터링은 이번 범위에서 제외한다.

### 3-1. 페이지에 반드시 넣을 "오해 방지" 기준

| 오해 | 실제 | 배지 |
|---|---|---|
| 기준금리가 0.25%p 내리면 내 대출금리도 즉시 0.25%p 내린다 | 변동금리 대출은 기준지표(COFIX·금융채 등)에 가산금리를 더한 구조이며, 기준지표가 기준금리와 같은 폭으로 움직이지 않을 수 있고, 내 금리는 **약정한 재산정 주기(예: 6개월·12개월)가 돌아와야** 바뀐다 | `참고` |
| 고정금리 대출도 바뀐다 | 고정금리 기간 중에는 기준금리와 무관하게 약정 금리 유지 | `참고` |

## 5. 입력값 설계

| 입력 항목 | `data-` / id (가칭) | 유형 | 기본값 | 범위·검증 | 비고 |
|---|---|---|---|---|---|
| 대출잔액 | `balance` | 숫자(원), 만원 단위 표기 | 300,000,000 | 1만원 ~ 50억원 | 현재 남은 원금 |
| 현재 연이율 | `rateNow` | 숫자(%) | 4.00 | 0.00 ~ 20.00, 소수 2자리 | 약정서·앱의 현재 적용금리 |
| 금리 입력 방식 | `rateMode` | 토글 | 변동폭 | `delta` / `target` | |
| 변동폭 | `rateDelta` | 숫자(%p) + 칩(−1.0/−0.5/−0.25/+0.25/+0.5/+1.0) | −0.25 | −5.00 ~ +5.00 | `delta` 모드 |
| 변경 후 연이율 | `rateNew` | 숫자(%) | 3.75 | 0.00 ~ 20.00 | `target` 모드. 두 모드는 서로 동기화 |
| 남은 기간 | `months` | 년 + 개월 입력 → 내부 개월 수 | 30년 0개월 (360) | 1 ~ 600개월 | |
| 상환방식 | `repay` | 세그먼트 | 원리금균등 | `annuity` / `equalPrincipal` / `bullet` | |

- URL 파라미터: `b`, `r0`, `r1`(또는 `d`), `m`, `repay` — 공유 링크로 상태 복원 (`url-state.js` 패턴).
- 변경 후 금리가 0% 미만이 되는 변동폭 입력은 0%로 클램프 + 안내 문구.
- MVP 제외: 거치기간, 금리 변경 적용 시작 시점(n개월 후 재산정), 혼합형(고정→변동 전환). → 설계 단계에서 v2 후보로 기록.

## 7. 계산 로직

### 7-1. 변수 정의

| 기호 | 의미 | 단위 |
|---|---|---|
| `P` | 현재 대출잔액(남은 원금) | 원 |
| `R0` | 현재 연이율 | 소수 (4.00% → 0.04) |
| `R1` | 변경 후 연이율 = `R0 + Δ` (변동폭 모드) 또는 직접 입력 | 소수 |
| `Δ` | 금리 변동폭 | 소수 (0.25%p → 0.0025) |
| `n` | 남은 기간 | 개월 (정수, ≥1) |
| `i` | 월 이율 = `R / 12` | 소수 |
| `k` | 회차 (1 ~ n) | — |

공통 가정 (모두 화면에 명시, `시뮬레이션`):
- 월 이율은 연이율 ÷ 12 (실제 은행 일할 계산·365일 기준과 소액 차이 가능).
- 변경 후 금리는 **즉시 적용되어 남은 기간 내내 유지**된다고 가정.
- 원 단위 표시 반올림은 **표시 단계에서만** 수행 (내부 계산은 실수).

### 7-2. 원리금균등 (`annuity`)

```text
i > 0 :  M = P × i × (1+i)^n / ((1+i)^n − 1)
i = 0 :  M = P / n
총이자   I = M × n − P
```

### 7-3. 원금균등 (`equalPrincipal`)

```text
회차별 원금   C = P / n
k회차 이자    I_k = (P − C × (k−1)) × i
k회차 상환액  M_k = C + I_k
첫 달 상환액  M_1 = P/n + P × i
마지막 달     M_n = P/n + (P/n) × i
총이자        I = i × P × (n+1) / 2   (루프 합계와 동일 — 검증용으로 두 방식 모두 테스트)
```

- 대표 월 상환액 = **첫 달(M_1)** 로 표시하고 "매달 줄어듦, 마지막 달 ○○원" 보조 표기.
- 월 부담 증감 = 첫 달 차이 = `P × (i1 − i0)`.

### 7-4. 만기일시상환 (`bullet`)

```text
월 이자      M = P × i
총이자       I = P × i × n
만기 상환    P (마지막 달에는 M + P 납부)
```

- 월 부담 증감 = `P × Δ / 12` — 상환방식 중 금리 민감도가 가장 직접적.

### 7-5. 빠른 비교표

```text
for d in [−0.01, −0.005, −0.0025, +0.0025, +0.005, +0.01]:
  R = max(0, R0 + d)
  행 = { R, 월상환액(R), 월상환액(R) − 월상환액(R0), 총이자(R) − 총이자(R0) }
```

- `R0 + d < 0` 인 행은 0%로 계산하고 "0% 하한 적용" 표기.

### 9-2. 금리 구조 설명 범위 (이해에 필요한 수준까지만)

- **내 대출금리 = 기준지표 금리 + 가산금리 − 우대금리** `참고`
- **기준지표**: 주담대 변동형은 주로 COFIX(은행 자금조달비용 지수, 은행연합회 매월 공시), 신용대출·일부 주담대는 금융채(은행채) 금리. 둘 다 시장금리를 반영해 움직이며 기준금리와 **같은 폭·같은 날 움직이지 않는다**.
- **변동주기**: 6개월·12개월 등 약정 주기마다 그 시점 기준지표로 재산정 → 기준금리 결정일과 내 금리 변경일이 다르다.
- **고정·혼합형**: 고정 기간 중에는 변화 없음.
- 세부 COFIX 산정 방식(신규취급액·잔액 기준 차이 등)은 1문장 이상 확장하지 않는다.

### 10-4. FAQ (6개)

1. **Q. 기준금리가 0.25%p 내리면 제 대출금리도 바로 0.25%p 내려가나요?**
   아닙니다. 변동금리 대출은 COFIX나 금융채 금리 같은 기준지표에 가산금리를 더해 정해지며, 기준지표는 기준금리와 같은 폭으로 움직이지 않을 수 있습니다. 또한 약정한 변동주기(예: 6개월)가 돌아와야 금리가 재산정되므로 반영 시점도 사람마다 다릅니다.
2. **Q. 고정금리 대출도 기준금리에 따라 이자가 바뀌나요?**
   고정금리 기간 동안에는 약정 금리가 유지되어 기준금리와 무관합니다. 혼합형은 고정 기간이 끝나고 변동금리로 전환되는 시점부터 영향을 받습니다.
3. **Q. 원리금균등과 원금균등 중 어느 쪽이 금리 변화에 더 민감한가요?**
   첫 달 월 상환액 변화는 원금균등이 더 크게 보입니다(잔액 전체에 금리 차이가 붙기 때문). 다만 원금균등은 원금이 빠르게 줄어 총이자 증감은 원리금균등보다 작습니다. 매달 이자만 내는 만기일시상환은 금리 변화가 월 부담과 총이자에 가장 직접적으로 반영됩니다.
4. **Q. 금리 인상과 인하의 효과가 같은 크기인가요?**
   원리금균등은 같은 폭이라도 인상 시 늘어나는 금액이 인하 시 줄어드는 금액보다 약간 큽니다. 3억원·30년·4% 기준 +0.5%p는 월 약 8만 8천원 증가, −0.5%p는 약 8만 5천원 감소로 계산됩니다.
5. **Q. 다음 기준금리 결정은 언제인가요?**
   한국은행 공식 일정상 2026년 남은 통화정책방향 결정회의는 10월 22일(목)과 11월 26일(목)입니다. 현재 기준금리는 2026년 8월 27일 결정된 연 3.00%입니다.
6. **Q. 계산 결과가 은행 안내 금액과 조금 다른 이유는?**
   은행은 실제 일수(일할) 기준으로 이자를 계산하고 원 단위 절사 규칙을 적용하지만, 이 계산기는 연이율÷12의 월 이율로 계산합니다. 거치기간, 중도 일부상환, 우대금리 변경도 반영하지 않으므로 참고용으로 활용하세요.
7. **Q. 금리가 올라 부담이 커지면 어떻게 해야 하나요?**
   더 낮은 금리 상품으로 갈아타는 대환대출, 여유자금으로 원금 일부를 갚는 중도상환을 검토할 수 있습니다. 두 경우 모두 중도상환수수료를 함께 따져야 하므로 관련 계산기로 이어서 확인하세요.
