## 1. 페이지 목적

기존 URL을 2027년 기준 비교의 대표 진입점으로 갱신한다. `median-income-calculator`는 만들지 않는다. 중위소득 비율 조회와 네 급여 소득기준 비교가 기존 페이지의 사용자 질문·결과와 동일하기 때문이다. 별도 페이지가 필요한 시점은 복지 비교와 다른 독립적 목적이 확인될 때이며, 키워드만 다르다는 이유로 분리하지 않는다.

조사는 프로젝트 문서 → 등록 목록·인벤토리 → 실제 데이터·페이지·스크립트 → 공식 웹 자료 순서로 진행했다. 읽은 기준은 `AGENTS.md`, `AGENT.md`, `CONTENT_GUIDE.md`, `docs/REPORT_CONTENT_GUIDE.md`, `docs/ARCHITECTURE.md`, `docs/QUALITY_SCORE.md`, `docs/SECURITY.md`, `DEPLOY_CHECKLIST.md`다. 목록은 `src/data/tools.ts`, `src/data/reports.ts`, `docs/sheets/page_inventory_2026-10-07.csv`를 대조했다. 인벤토리의 존재 표시는 구현 상태의 보조 근거이며 현재 기능은 소스에서 확인했다.

## 2. 사용자 니즈

| 사용자 질문 | 제공할 답 | 다음 행동 |
|---|---|---|
| 2027년 우리 가족 중위소득 100%는 얼마인가요? | 가구별 월 기준액, 전년 대비 변화 | 기준표 확인 |

사용자에게 최종 수급자격 확정을 약속하지 않는다. 페이지명에 수급 자격을 유지하더라도 결과 제목은 ‘급여별 소득기준 비교’로 제한한다. 의료급여의 부양의무자 등 추가 요건과 교육급여의 학생 요건은 금액 비교와 별도 문장으로 노출한다.

### 2027 급여별 선정기준

생계 32%, 의료 40%, 주거 48%, 교육 50%. 비율은 2026년과 같다. 1~6인 금액은 공식 발표표 인용이다. 7인 생계·의료·교육 금액은 공식 중위소득에 비율을 적용한 **시뮬레이션**이며, 고시 표 대조 전 공식 금액으로 승격하지 않는다. 주거 7인 금액은 국토교통부 원문에서 확인한 **공식** 수치다.

| 가구원 | 생계 32% | 의료 40% | 주거 48% | 교육 50% |
|---|---:|---:|---:|---:|
| 1인 | 875,533 | 1,094,417 | 1,313,300 | 1,368,021 |
| 2인 | 1,433,806 | 1,792,258 | 2,150,710 | 2,240,323 |
| 3인 | 1,829,789 | 2,287,236 | 2,744,684 | 2,859,046 |
| 4인 | 2,217,563 | 2,771,954 | 3,326,345 | 3,464,943 |
| 5인 | 2,580,166 | 3,225,208 | 3,870,249 | 4,031,510 |
| 6인 | 2,921,344 | 3,651,680 | 4,382,016 | 4,564,601 |
| 7인 | 3,248,853 ※ | 4,061,066 ※ | 4,873,279 | 5,076,333 ※ |

※ 표시값은 `floor((중위소득 × 정수비율 + 50) / 100)`로 계산한 설계 참고값이다. **구현 전 재확인 필요:** 생계·의료·교육 7인 고시 표 직접 대조. 미대조 상태로 출시할 경우 해당 급여 7인 이상 결과를 숫자 없이 ‘공식 기준표 재확인 필요’ 문장으로 막는다. 1~6인 결과와 중위소득 비율·주거급여 7인 이상 비교는 확인된 범위에서 제공 가능하다.

### 8인 이상 산정 방식

2027년 중위소득은 `M(n) = M(7) + (M(7) - M(6)) × (n - 7)`이다. 1인 증가액은 자체 계산 시 1,023,464원이며 8인 11,176,129원, 9인 12,199,593원이다. 이 산식으로 만든 금액에는 시뮬레이션 배지를 붙인다. [보건복지부고시 제2026-157호 제2조](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000283464).

생계·의료는 **각 급여의 7인 기준액과 6인 기준액 차이**를 해당 급여 7인 금액에 가산한다. 주거도 동일하게 자체 기준액 차이를 사용한다. 따라서 중위소득을 먼저 확장한 뒤 비율을 곱하는 방식을 모든 급여에 일괄 적용하지 않는다. 교육은 첨부 고시에서 산식을 직접 대조한 후 별도 저장한다. [생계·의료 고시 제3·5조](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000283464), [주거 고시](https://police.molit.go.kr/USR/I0204/m_14993/dtl.jsp?gubun=4&idx=18946).

주거 8인 예시: `4,873,279 + (4,873,279 - 4,382,016) = 5,364,542원`. 반면 `11,176,129 × 48%`를 반올림하면 5,364,542원이나, 다른 급여·가구 수에서도 항상 같다고 가정할 수 없다. 급여별 정수 원자료와 가산 규칙이 우선이다.

### 2026 대비 변경점과 보류 항목

4인 중위소득은 435,147원 증가했고 공식 발표 인상률은 6.70%다. 4인 급여 기준 변화는 생계 2,078,316→2,217,563원, 의료 2,597,895→2,771,954원, 주거 3,117,474→3,326,345원, 교육 3,247,369→3,464,943원이다. 원자료는 공식, 증가액·같은 입력액의 연도별 비교는 시뮬레이션이다. [공식 발표](https://www.korea.kr/briefing/pressReleaseView.do?newsId=156772464).

중위소득 결정 방법도 개편됐다. 페이지 본문에는 제도 배경으로만 설명하고 통계 증가율로 다음 연도 값을 직접 예측하지 않는다. 임차 기준임대료와 교육활동지원비 변경은 각 상세 계산기 갱신 사항이며 이 페이지 결과 금액으로 제공하지 않는다. [보건복지부 발표](https://www.mohw.go.kr/gallery.es?act=view&bid=0003&list_no=380303&mid=a10605040000).

**구현 전 재확인 필요:** 2027 국민기초생활보장·의료급여 사업안내의 공제·재산·차량·부양의무자 규정, 보장가구 범위와 예외, 사업별 세부 적용일, 교육급여 첨부 표와 부칙. 최신 지침을 이번 조사에서 확인하지 못했으므로 ‘미발표’ 또는 ‘확정되지 않음’으로 단정하지 않는다. 이 페이지는 해당 세부 규칙을 계산하지 않도록 설계한다.

### 입력 명세

| 입력 | 기본값·범위 | 처리 |

1. `CalculatorHero`: H1·한 줄 설명. 연도는 제목 텍스트로, 배지는 공식/시뮬레이션만 사용.

## 5. 계산 로직 또는 데이터 구조

### 연도별 데이터 분리

공식 원자료는 정수 원 단위로 관리한다. `src/data/welfareThresholds.ts`를 새 공통 데이터 파일로 설계하되 공개 페이지를 추가하지 않는다.

```ts
type SourceBadge = '공식' | '참고' | '시뮬레이션' | '추정';
type BenefitKey = 'livelihood' | 'medical' | 'housing' | 'education';
type MoneySource = {
  amount: number | null;
  badge: SourceBadge;
  sourceId: string;
  verified: boolean;
};
type YearCriteria = {
  year: 2026 | 2027;
  effectiveFrom: string;
  checkedAt: string;
  medianBySize: Record<number, MoneySource>; // 1~7
  ratios: Record<BenefitKey, number>; // 32, 40, 48, 50
  benefitBySize: Record<BenefitKey, Record<number, MoneySource>>;
  expansion: Record<BenefitKey | 'median', {
    method: 'difference_7_6' | 'fixed_increment';
    increment?: number;
    verified: boolean;
    sourceId: string;
  }>;
};
```

`sources`에 기관명·자료 제목·URL·발표일·시행일·확인일·표/조문 위치를 기록한다. `null`과 `verified:false`를 0원으로 변환하지 않는다. 고시 표 대조가 끝나면 해당 셀만 verified를 변경하고 확인일을 기록한다. 공식표 금액을 런타임에서 비율 곱셈으로 재생성하지 않는다.

`WBE_2026_THRESHOLDS`는 2026 데이터 호환 export로 유지한다. 현재 참조자는 생계·주거·교육·재산 계산기, 경기 청년 재직자 계산기, 청년월세 계산기, 부모님 복지 진단이다. 기존 공제 상수까지 같이 가져가는 파일도 있으므로 2027 값으로 일괄 치환하면 2026 사업 금액이 바뀔 수 있다. 각 소비자는 별도 갱신 전까지 2026 값을 유지한다. `householdIncome.ts`와 복지지원금 리포트의 독립 기준표도 이번 갱신에 자동으로 바뀌지 않는다.

### 수식과 판정

- `M = selectedYear.median(n)`.
- `A = 검증된 입력 월 금액`.
- `P = 100 × A / M`.
- `T_b = 해당 연도·가구원·급여의 검증된 선정기준`.
- `gap_b = T_b - A`.
- `A <= T_b`이면 ‘기준 이하’, 아니면 ‘기준 초과’. 같으면 ‘기준과 같음 · 차이 0원’ 보조 문장.
- 양의 gap: ‘기준까지 X원 남음’. 음의 gap: ‘X원 초과’. 이 차액은 생계급여 지급액이 아님.
- 비율은 공통 가이드에 맞춰 화면에서 `Math.round(P)`로 정수 % 표시. 판정에는 반올림 비율을 사용하지 않음. ‘비율은 반올림, 비교는 원 단위’ 설명 포함.
- 급여기준 미검증 시 해당 행의 금액·차액·비교를 계산하지 않음. 중위소득 비율과 확인된 다른 행은 유지.
- 월소득 모드에서도 수식은 동일하지만 제목에 ‘월 소득 단순 비교’, 각 결과 근처에 ‘소득인정액 산정 전 금액 비교’ 문장을 반복. 수급가능/불가능으로 해석하지 않음.
- 2026 대비 표는 같은 A·n을 고정해 양 연도 T와 gap을 계산. 소득·재산 조건까지 같다는 전제는 붙이지 않음.

8인 이상 급여는 `T_b(n) = T_b(7) + (T_b(7)-T_b(6)) × (n-7)`를 **각 고시에서 확인한 급여에만** 적용한다. 2026 생계는 고시의 고정 가산액 306,943원 등 해당 연도 규칙을 저장한다. 교육의 가산 방식이 확인되기 전 8인 이상 행은 막는다. 알 수 없는 가구원을 기존 JS처럼 4인 기준으로 대체하지 않는다.

### 대표 예시: 시뮬레이션

2027년 4인, 월 소득인정액 3,000,000원:

| 항목 | 결과 |
|---|---|
| 중위소득 비율 | 원비율 약 43.29076%, 화면 43% |
| 생계 | 2,217,563원 기준, 782,437원 초과 |
| 의료 | 2,771,954원 기준, 228,046원 초과 |
| 주거 | 3,326,345원 기준, 326,345원 남음 |
| 교육 | 3,464,943원 기준, 464,943원 남음 |

같은 값을 월소득 모드에 넣으면 숫자는 같아도 ‘월 소득 단순 비교’이고 자격 가능성은 표시하지 않는다. 소득인정액 모드도 추가 요건 확인을 생략할 수 없다.

2027년 4인, A=2,150,000원: 생계 기준까지 67,563원 남음. 같은 A는 2026 생계 기준보다 71,684원 초과한다. ‘2027년 소득기준 비교에서는 이하’로만 표현한다.

### 경계값과 기대 동작

| 조건 | 기대 결과 |
|---|---|
| 2027·4인·A=0 | 비율 0%, 네 급여 기준 이하. 소득 외 요건 경고 유지 |
| 각 급여 T-1 / T / T+1 | 각각 1원 남음 / 기준과 같음 / 1원 초과. 모든 검증된 연도·가구원 조합 확인 |
| 생계 A=2,217,564 | 비율 표시가 32%로 반올림돼도 1원 초과 |
| 의료 A=2,771,955 | 의료 1원 초과. 주거·교육은 별도 비교 |
| 주거 A=3,326,346 | 주거 1원 초과. 교육은 이하 |
| 교육 A=3,464,944 | 교육 1원 초과. 모든 행이 초과 |
| A=M=6,929,885 | 비율 100%, 네 급여 초과 |
| 7인→8인 | M:10,152,665→11,176,129. 주거:4,873,279→5,364,542. 미검증 급여는 차단 |
| 8인→9인 | 중위소득 증가액 1,023,464원 유지. 가산 금액은 시뮬레이션 표시 |
| n=0·-1·1.5·21 | 가구원 오류. 임의 1인/4인 기준으로 계산하지 않음 |
| A 빈 값·-1·1.5·문자·NaN·Infinity·10억 초과 | 오류 또는 미입력. 0원 결과로 대체하지 않음 |
| A=10억 | 유효 최대값, 비율·금액 overflow 없이 표시 |
| year=2028 또는 비허용 mode URL | 오류 안내 후 허용된 기본 선택으로 복구, 입력액은 비움 |
| 모드 전환 | 금액 초기화, 이전 종류 금액이 자동 승계되지 않음 |

기존 `judgeBenefit`의 ±5% 경계구간을 이 화면에 승계하지 않는다. ‘기준 근접’ 설명이 필요하더라도 이하/초과 비교를 대체하지 않고 별도 문장으로만 제공한다.

## 6. 결과 화면 방향

첫 결과는 선택연도·가구원·입력액 종류를 한 줄로 명시하고 3개 KPI를 사용한다: 기준 중위소득 월 금액(공식 또는 가산 시뮬레이션), 입력한 월 금액, 중위소득 대비 비율(시뮬레이션). 금액 미입력 시 기준액만 채운다.

급여별 표는 ‘급여 / 공식 선정비율 / 월 기준액 / 비교 / 남은·초과 금액’ 순서다. 공식 금액에는 공식, 자체 비교·차액에는 시뮬레이션을 붙인다. 한 카드 안에서도 출처 성격을 나눠 표시한다. 미검증은 별도 배지가 아니라 본문 ‘구현 전 재확인 필요’로 관리하며 실제 사용자 화면에는 ‘공식 기준표 확인 후 안내 예정’ 문장을 사용한다.

4개 수평 바는 같은 축으로 입력액과 급여 기준을 표시하고 텍스트 표를 함께 제공한다. 입력액이 축 최대를 넘어도 숫자는 잘라내지 않고 마커가 표시 범위를 벗어났다는 문장을 제공한다. 외부 차트 라이브러리 추가 없이 CSS로 구성한다. 색만으로 이하/초과를 구분하지 않는다.

의료 행에는 ‘부양의무자 등 별도 요건 확인’, 교육 행에는 ‘학생 요건·신청 절차 확인’, 전체 결과 아래에는 ‘소득기준 비교 결과이며 최종 수급 여부는 신청 후 조사로 결정됩니다’ 문장을 배치한다. ‘4개 급여 수급 가능’ 같은 합산 판정과 의료·교육 기준액을 지급액처럼 보여주는 카드는 금지한다.

모바일은 입력→KPI→급여별 카드 순서, 데스크톱은 기존 `SimpleToolShell` 활용. 320px에서 입력·카드가 넘치지 않아야 하며 긴 기준표만 가로 스크롤을 허용한다. 라벨·키보드 탐색·오류 연결·`aria-live="polite"` 적용을 설계한다.

## 7. SEO 본문 방향

H1은 ‘2027 기준 중위소득·복지급여 수급 자격 계산기’. H2는 ‘내 소득은 기준 중위소득 몇 %일까’, ‘생계·의료·주거·교육급여 소득기준 비교’, ‘2026년과 무엇이 달라졌을까’, ‘월소득과 소득인정액의 차이’, ‘신청 전 확인할 사항’으로 구성한다. 평균소득·소득 순위·건강보험료를 중위소득 자격과 혼동하지 않도록 본문에서 다룬다.

### intro 초안: 4단락, 각 150자 이상·합계 600자 이상

2027년 복지급여 신청을 준비하거나 올해 소득기준을 조금 넘었던 가구라면 새 기준을 같은 조건으로 다시 비교해 볼 필요가 있습니다. 가족이 늘거나 줄었을 때, 일을 쉬면서 소득이 달라졌을 때, 신청 결과에서 소득인정액을 안내받았을 때에도 가구원 수와 적용 연도를 먼저 확인하세요. 이 계산기는 생계·의료·주거·교육급여의 소득기준을 한 화면에 놓아 어느 기준을 추가로 살펴볼지 판단하는 데 도움을 줍니다.

기준 중위소득은 정부가 급여와 여러 복지사업의 기준으로 사용하는 가구원 수별 금액입니다. 계산기는 선택한 가구의 기준 중위소득으로 입력한 월 금액을 나누어 비율을 구하고, 급여별 선정기준과 원 단위로 비교합니다. 2027년 급여별 비율은 생계 32%, 의료 40%, 주거 48%, 교육 50%입니다. 기준비율이 같아도 가구원 수와 연도가 달라지면 비교 금액이 달라지므로 다른 가족의 결과를 그대로 적용하지 마세요.

결과의 ‘기준 이하’는 입력한 금액이 해당 급여의 소득기준을 넘지 않는다는 뜻입니다. 생계급여 기준을 초과하더라도 주거급여나 교육급여의 기준 이하일 수 있으므로 각 행을 따로 읽으세요. 남은 금액은 기준선까지의 차이이며 받을 지원금이 아닙니다. 비율은 읽기 쉽게 반올림하지만 이하와 초과는 원 단위 금액으로 판단합니다. 기준과 아주 가까운 경우에는 표시 비율보다 입력액과 기준액의 차이를 확인하는 것이 중요합니다.

월급이나 가구의 월소득은 법적 의미의 소득인정액과 같지 않습니다. 실제 조사에서는 소득 공제와 재산의 소득환산액, 금융재산·자동차·부채 인정 여부 등이 반영될 수 있고 급여별 추가 요건도 확인합니다. 월소득 단순 비교를 선택했다면 결과를 수급자격으로 해석하지 마세요. 소득인정액을 모르면 연결된 상세 계산기에서 산정 구조를 살펴보고, 최종 신청 전에는 복지로와 주소지 읍면동 주민센터에서 해당 연도 기준을 확인하세요.

공식 수치가 들어간 문단에는 3번 섹션의 공식 출처를 가까이 연결한다. intro·FAQ·출처는 SSG HTML에서 읽히게 하고 FAQ는 데이터 파일의 `{q,a}` 배열로 관리한다. `SeoContent`의 자동 FAQ 구조화 데이터를 사용하고 별도 중복 스키마를 만들지 않는다.

## 9. 리스크·주의사항

- 월소득을 소득인정액으로 부르지 않는다. 월소득 모드의 비교는 참고 목적이며 계산 결과 배지는 시뮬레이션이다.
- 하나의 소득인정액을 모든 급여의 실제 조사 금액으로 보장하지 않는다. 급여별 공제·가구 특례가 다르면 각 기준에 맞는 금액으로 다시 비교하도록 안내한다.
- 네 급여의 기준 이하를 최종 자격으로 표시하지 않는다. 부양의무자·가구 구성·학생·시설수급 등 범위와 예외는 공식 조사에서 확인한다.
- 기존 소득인정액 산식은 지역 구분·재산 비례 배분·일반재산 환산·근로공제 60만원 상한·차량 경고만 적용하는 간이 로직이다. 최신 법적 산식으로 검증된 것처럼 2027 화면에 이어 쓰지 않는다. 상세 페이지 개선은 별도 작업으로 기록한다.
- 2027 확정 기준을 2026년 현재 적용 기준과 혼동하지 않는다. 제목·연도 선택·결과·공유문에 선택연도와 적용 시점을 표시한다.
- 2026 export를 2027로 덮어쓰면 교육·청년월세·부모님 진단 등 다른 페이지가 잘못 갱신된다. 연도별 원자료와 기존 호환 export를 유지한다.
- 배지는 **공식 / 참고 / 시뮬레이션 / 추정** 네 종류만 허용한다. 연도·분야·‘확인 필요’·‘자가 점검’은 일반 텍스트이며 배지로 사용하지 않는다. 이 페이지에서 자체 추정치를 만들 필요는 없으므로 추정 배지는 기본적으로 쓰지 않는다.
- URL 공유에는 민감한 소득 수치가 포함될 수 있다. 기본 실시간 URL state는 연도·가구원·입력 모드만 보존하고, 금액 포함은 별도의 ‘금액을 포함해 공유’ 사용자가 선택한 행동으로만 생성한다. 이름·주소·주민번호·재산 내역을 수집하지 않는다. 계산 입력을 분석 이벤트나 로그로 전송하지 않는다.
- 숫자·열거값 allowlist를 적용하고 사용자 입력을 `textContent`로 출력한다. 공유 링크의 수치도 동일 범위 검증하며 임의 값에 4인 기준을 반환하지 않는다.
