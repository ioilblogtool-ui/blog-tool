# 계산기 3종 배포 전 최종 점검

점검일: 2026-10-07. **판정: 배포 보류.** 개별 계산기 검증과 프로덕션 빌드는 통과했으나 저장소 전체 타입 검사가 실패한다. 커밋·push·배포는 수행하지 않았다.

후속 요청: 위 점검 결과와 기존 타입 오류 397개를 사용자에게 알린 뒤 사용자가 “커밋 푸시”를 요청했다. 이 명시적 후속 요청에 따라 세 계산기 변경을 커밋·푸시한다. `AGENT.md`의 전체 검사 통과 기준에 대한 이번 작업의 예외이며, 전체 검사 통과 또는 기존 오류 해결로 기록하지 않는다. 빌드 성공 기준은 유지한다. 관련 없는 잠금 파일·업로드 CSV·다른 콘텐츠 기획 문서는 제외한다. 실제 커밋·푸시 결과는 작업 응답과 Git 기록으로 확인한다.

## 이번 점검에서 수정한 사항

- 대출 페이지의 미지원 `CalculatorHero.badges` 속성을 제거했다.
- 대출 계산기를 도구 목록의 `대출·금융` 분류에 등록했다. 홈 분류도 함께 검증했다.
- 대출 전용 OG 이미지를 생성하고 페이지에 연결했다. 세 페이지 OG는 모두 1200×630이다.
- 대출 금리 빈칸을 0%로 계산하지 않도록 막았다. 실제 0 입력은 허용한다.
- 대출잔액 범위 초과 시 임의로 상한에 맞춰 계산하지 않고 오류를 표시한다.
- 대출 금리 0~20% 상하한 적용 시 실제 적용 금리와 비교표 안내를 표시한다.
- 대출 페이지 세션 녹화·광고를 비활성화하고 referrer 정책을 맞췄다. 입력값이 공유 링크와 주소 기록에 남을 수 있다는 안내를 추가했다.
- 연말정산 공유 안내를 수정했다. 소득·지출 정보를 포함하는 링크의 공유 대상을 확인하도록 안내한다.
- 연말정산 소개를 5단락·800자 이상으로 보강하고 부족한 FAQ 답변을 3문장으로 보완했다.

## 브라우저 확인

- 복지급여: 2027년 4인, 소득인정액 300만원에서 생계·의료 기준 초과, 주거·교육 기준 이하와 차액을 확인했다. 단순 월소득과 소득인정액 구분 및 상세 계산기 연도 안내가 표시된다.
- 연말정산: 기납부 실제 0 입력과 빈칸 구분, 결정세액 3,387,500원 표시를 확인했다. 기존 설계 검증 기록에는 기납부 400만원 환급·음수 오류 복구·공유 복원이 포함되어 있다.
- 대출: 원리금균등 기본 월 차액 −42,899원, 원금균등 −62,500원, 만기일시 원금 별도 안내, 빈 금리 오류, 잔액 초과 오류, 20% 상한 안내와 초기화를 확인했다.
- 세 페이지 모바일 문서 가로 넘침이 없음을 확인했다(이번 브라우저 실제 문서 폭 360px). 이전 설계의 여러 해상도 기록은 해당 문서에 남아 있다. 이번 결과를 별도의 모든 기기 검증으로 확대 해석하지 않는다.
- 도구 목록 `대출·금융` 필터와 홈 모바일 검색 `대출금리`에서 신규 계산기 노출을 확인했다.
- 세 페이지 광고·세션 녹화 설정과 공유 안내를 검토했다. 실제 개인정보 대신 가상 입력값으로 검사했다.

## 배포를 막는 항목과 다음 조치

전체 타입 검사 397개 오류를 해결해야 한다. 주요 분포는 `src/pages/reports/index.astro` 203개, `src/components/SiteHeader.astro` 16개, `src/pages/index.astro` 4개다. 이외 기존 페이지의 미지원 Hero/SEO 속성과 데이터 타입 오류 등이 있다. 대출 페이지에서 발견한 신규 속성 오류를 제거한 후 총 오류는 최초 398개에서 397개로 줄었다. 대상 한정 검사 통과가 전체 검사 실패를 대체하지 않는다.

1. 위 공통 페이지·컴포넌트 및 나머지 기존 타입 오류를 별도 범위로 정리해 수정한다.
2. `npm run check:all`과 `npm run build`를 다시 통과시킨다.
3. 커밋 대상 파일을 확인한다. 기존 `package-lock.json` 수정과 업로드 인벤토리 CSV는 이번 점검에서 생성한 변경이 아니므로 의도 확인 없이 포함하지 않는다. 임시 점검 로그·설정은 커밋 대상에서 제외한다.
4. 실제 배포 환경에서 첫 로드·캐시·OG 노출을 확인한다. 프로덕션 smoke test, 검색엔진 반영, 스크린리더 실기기 검사는 아직 수행하지 않았다.

## 공식 자료와 계산의 한계

대출 기준금리 카드의 날짜·수치는 [한국은행 기준금리 추이](https://www.bok.or.kr/portal/singl/baseRate/list.do?dataSeCd=01&menuNo=200643) 원문을 대조했다. 카드의 기준금리는 대출 금리에 자동 전가하지 않는다. 대출 계산은 연이율÷12와 고정된 잔여 기간을 가정한 시뮬레이션이며 실제 금융기관 일할 계산·우대조건·수수료와 차이가 있다.

연말정산 자녀·연금 세액공제는 [국세청 세액공제 안내](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7875&mi=6439)와 대조했다. 모든 개인별 특례를 포괄하는 신고 도구가 아니다. 복지급여 원문·검증 상태는 `src/data/welfareThresholds.ts` 및 기존 2027 설계 문서를 따른다. 미검증 세부 기준은 구현 전 재확인 대상으로 유지한다.

공식 원자료에서 자체 계산한 결과는 시뮬레이션으로 표시한다. 이번 점검으로 미확정 정책 기준을 확정 상태로 변경하지 않았다.
