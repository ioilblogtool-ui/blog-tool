4대보험 소계를 ‘계산 가능 항목 소계 · 단수 가정’으로 표시하고 상태 배지에도 단수 처리 가정을 명시했다. 요율 확인과 최종 고지액 확정을 혼동하지 않게 한다.

브라우저 검증 제한: Windows 브라우저 URL을 확실히 확인할 수 없어 자동화가 정책상 중단됐다. 실제 데스크톱/모바일 레이아웃·클릭 검증은 미실시다. 이 제한을 안내한 뒤 사용자가 배포를 요청했다. 이를 시각 검증 완료로 취급하지 않는다.

실제 배포 설정: `.github/workflows/deploy.yml`은 main push 시 GitHub Pages Actions를 실행한다. 문서 일부의 Cloudflare 설명보다 현재 워크플로를 우선한다. 커밋 SHA·배포 작업 결과·라이브 HTTP 확인은 실행 로그/배포 응답에서 별도로 확인한다.
