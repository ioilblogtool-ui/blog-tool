# STEP 03 해외주식 양도소득세 계산기 구현 인계

작성일: 2026-11-10. 신규 경로: `/tools/overseas-stock-capital-gains-tax-calculator/`.

## 범위와 구조

2026 귀속 원화 실현손익의 일반 사례 전용 계산기. 기존 부동산·국내주식·환차익 계산기의 목적이나 엔진을 바꾸지 않는다. 데이터 TS → 안전한 JSON → 브라우저 ES module, DOM 없는 BigInt 계산 모듈, 기존 BaseLayout·SimpleToolShell·CalculatorHero·InfoNotice·SeoContent를 사용한다.

- 상품·과세대상 거주 요건·일반 20% 세율·국내 과세주식 혼합 없음·특례/외국납부세액공제/기납부액 등 조정 없음의 모든 확인이 있어야 입력을 연다. 모르는 항목은 계산하지 않는다.
- 합계/계좌별 입력(최대 20행). 계좌 이름·번호·종목명 미수집. 각 입력 최대 1조원은 서비스 입력 정책이다.
- 합계→계좌는 계좌 1로 이전, 계좌→합계는 이익·손실·별도 적격 비용을 합쳐 동일 경제적 값 보존. 합계가 필드 한도를 넘거나 입력이 잘못됐으면 모드 전환을 거절하고 원래 내역을 보존한다.
- 비용 포함이 기본. 별도 적격 비용을 선택한 경우만 차감해 중복 차감을 방지한다. 비용만 입력하고 이익·손실이 모두 빈 행은 오류로 안내한다.
- 기준 세금 성공 후 시나리오 활성화. 기준 수정은 기준/시나리오 무효화, 시나리오 수정은 시나리오 결과만 숨김, 시나리오 지우기는 기준 유지. 자격 변경은 금액/결과 초기화.
- 기본공제 잔여는 0~250만원, 순손실도 음수 세금·자동 환급·전년 이월을 생성하지 않는다. 시나리오 차액은 매매수익과 구분한다.
- 입력값·결과는 메모리에서만 사용. 주소/저장소/분석 로그 미포함. 공유는 canonical 주소만. 광고·세션 녹화 비활성. 새 추적 이벤트는 추가하지 않았다.
- 정적 예시·귀속연도 확인·12문항 FAQ·공식 출처·관련 링크·FAQPage/WebApplication·사이트 목록·사이트맵·전용 OG 등록.

## 공식 규칙 검증 기록

일반 국세 20% 적용 사례만 제한한다. 다른 세율을 상품명으로 자동 판정하지 않는다. 아래 확인 근거로 규칙 `overseas-stock-general-2026-v1`을 `cross_checked`로 기록했다. 규칙/연도/지방세 기준/끝수 처리/필수 출처가 빠지면 근사 22%로 대체하지 않고 계산을 차단한다.

| 항목 | 적용 | 공식 근거 |
|---|---|---|
| 대상·손익통산·기본공제 | 일반 국외주식, 같은 연도 합산, 연 250만원 한 번 | [국세청 세액계산요령](https://webtv.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=8800&mi=12274) |
| 국세 일반 세율 | 공제 후 과세표준 × 20% | 위 국세청 안내 및 소득세법 제104조 제1항 제12호 일반 세율 |
| 지방세 일반 세율 | 같은 과세표준 × 2% | [지방세법 제103조의3 제1항 제12호 나목](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=03&joNo=0103&lsiSeq=282559&urlMode=lsScJoRltInfoR) |
| 국세 끝수 | 납부세액 10원 미만 버림; 원화 정수 입력으로 과세표준 소수 없음 | [국고금 관리법 제47조](https://law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1031453583) |
| 지방세 끝수 | 국세와 별개로 지방세 10원 미만 버림 | [지방세기본법 제59조](https://law.go.kr/lsInfoP.do?ancYnChk=0&lsId=011177), 국고금 관리법 준용 |

일반 사례에서 세액공제·감면·기납부세액 등 다른 조정이 없으므로 각 납부세액 단계에 끝수 처리를 적용한다. 국세 절사 후 그 10%를 지방세로 계산하지 않고 같은 과세표준에서 독립 계산한다. 예: 과세표준 499원 → 국세 90원, 지방세 0원, 합계 90원. 22%를 합계에 한 번 적용·절사하면 100원이므로 구분해야 한다.

국세청 거주 요건은 ‘양도일까지 계속 5년 이상 국내 주소·거소를 둔 거주자’로 안내하고 국적만으로 대체하지 않는다. 단기 거주 등 예외·특정주식·중소기업 등 다른 세율은 일반 엔진 밖이다. 국내 과세대상 주식 혼합은 공제 공유·통산·세율 배분 검토가 필요하므로 지원하지 않는다.
