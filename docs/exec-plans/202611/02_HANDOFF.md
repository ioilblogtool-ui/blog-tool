# STEP 02 국민연금 보험료 계산기 구현 인계

작성일: 2026-11-10. 경로: `/tools/national-pension-contribution-calculator/`.

## 구현 범위

- 기존 수령액 계산기와 별도 페이지. 2026·2027 같은 기준소득월액 요율 비교가 기본이며 자동 계산하지 않는다.
- 직장·지역가입자, 본인·회사·전체 부담, 월 차이와 같은 조건 12개월 환산. 2033년까지 고정 소득 요율 경로는 접힌 영역으로 제공한다.
- 월별 상·하한은 기존 `socialInsuranceRules.ts`, 계산은 `national-pension-contribution-core.js`를 재사용한다. 기존 공용 파일과 4대보험 구현을 수정하지 않았다.
- 입력 수정 즉시 이전 결과 숨김. 초기화, 입력 없는 canonical 주소 복사, 오류 안내, 정적 예시·FAQ·공식 출처·관련 링크, 검색 목록·사이트맵·전용 OG 이미지 등록.
- 입력값 저장·URL 포함·로그 전송 없음. 페이지 세션 녹화와 광고 로딩 비활성.

## 상세설계와 실제 구현의 차이

설계 NP-02의 **공식 규칙 검증을 완료한 월 보험료 추정**은 완료하지 않았다. 공용 데이터의 보험료 원 미만 단수 처리는 아직 `scenario`이므로 공식 추정으로 승격하지 않는다. 별도 모드에서 사용자가 단수 처리 가정을 명시적으로 확인한 경우에만 **참고 추정**을 제공한다. 이는 공식 고지액이 아니며 결과 카드에도 가정을 반복 표시한다. 확인하지 않으면 계산하지 않는다. 향후 단수 처리 공식 근거를 확보해 데이터 상태를 바꿀 때 공용 회귀 검증을 함께 수행해야 한다.

2027년 7월 이후 상·하한은 데이터에 없어 월별 계산을 차단한다. 과거 값을 연장하거나 0원으로 대체하지 않는다. 요율 비교는 상·하한과 단수 처리를 제외한 시뮬레이션이다. 12개월 환산은 실제 연간 합계가 아니다. 지원·감면·납부예외·복수 사업장 배분은 미지원.

## 검증

신규 검사: `node scripts/check-national-pension-contribution-calculator.mjs` (28개).
공용 회귀: `node scripts/check-four-insurance-calculator.mjs`.
전체 검사: `npm run check:all`, `npm run build`.

실행 결과는 아래 적용 스크립트가 추가 기록한다. 브라우저 화면·실제 클릭 QA는 이 환경에서 수행하지 못했으며 배포 전 별도 확인이 필요하다. OG PNG는 생성 후 육안 검토했다. 커밋·push·배포는 수행하지 않는다.

검증 완료: 신규 계산 검사 28개 통과, 기존 4대보험 공용 회귀 검사 통과, check:all 및 build 통과. 빌드 HTML에서 폼·결과·FAQ 스키마·스크립트·OG 경로와 광고/세션 녹화 미로드 확인. 브라우저 QA는 미실시.
